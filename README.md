## Déploiement — GitHub Pages

1. Créer un repo GitHub : `daat-ai`
2. Pousser tous les fichiers
3. Dans Settings → Pages → Source : `main` branch, `/ (root)`
4. Le site sera accessible à : `https://[username].github.io/daat-ai/`
