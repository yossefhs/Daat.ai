Déploiement GitHub Pages

Mettre à jour le site en ligne après modification du contenu

Workflow de mise à jour
  1. Ajoute ou modifie le contenu via les onglets Ajouter ou Générer page HTML
  2. Sauvegarde les fichiers générés dans le bon dossier du projet daat-ai
  3. Mets à jour data/simanim.json avec les nouvelles entrées
  4. Ouvre Terminal et navigue vers le projet :
    cd ~/Documents/Claude/Projects/daat-ai
  5. Committe et pousse :
    git add . && git commit -m "Ajout Siman XXX Seif X" && git push
  6. Le site se met à jour automatiquement en ~1 minute sur GitHub Pages ✅
Premier déploiement (à faire une seule fois)
Ces commandes créent le repo GitHub et activent GitHub Pages. À exécuter une seule fois depuis Terminal.
cd ~/Documents/Claude/Projects/daat-ai git init git add . git commit -m "Initial commit — DAAT.AI Siman 246" /usr/local/Cellar/gh/2.86.0/bin/gh auth login /usr/local/Cellar/gh/2.86.0/bin/gh repo create daat-ai --public --source=. --remote=origin --push # Activer GitHub Pages : /usr/local/Cellar/gh/2.86.0/bin/gh api repos/{owner}/daat-ai/pages -X POST -f source[branch]=main -f source[path]=/
⚠️ Remplace {owner} par ton nom d'utilisateur GitHub avant d'exécuter la dernière commande.
