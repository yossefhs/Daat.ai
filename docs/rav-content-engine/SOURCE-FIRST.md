# Source-first

`SOURCE → PREUVE → REFORMULATION → VALIDATION → PUBLICATION`

La publication n’appartient pas à cette phase. Tout candidat doit conserver une source, une preuve et un niveau de fiabilité. Une citation entre guillemets exige `quote_verified=true` ainsi qu’une preuve audio ; sinon le texte est présenté comme une reformulation attribuée avec prudence. Une source RED est bloquée, sans exception.
