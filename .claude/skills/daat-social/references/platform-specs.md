# Specs par plateforme (best practices 2026)

Règle d'or : **une variante par plateforme**, jamais le même texte copié-collé.
Les équipes qui adaptent le message par réseau ont un engagement nettement meilleur.
La **réponse / l'accroche utile en premier** (55 % des citations IA viennent des
30 premiers % du contenu).

| Plateforme | Format | Longueur | Ton | Hashtags | Visuel | Heure (Europe/IL) |
|------------|--------|----------|-----|----------|--------|-------------------|
| **LinkedIn** | Post texte, 1 enseignement clair | 800–1300 sig. | Pro, posé, « pourquoi c'est utile » | 3–5 ciblés | Carte OG | Mar–Jeu 8h–10h |
| **Instagram** | Caption + idée de carrousel (3–6 slides) | Caption 125–300 sig. | Inspirant, accessible | 8–15 (mix niche/large) | Carrousel charte DAAT | 11h–13h / 19h–21h |
| **Facebook** | Post communautaire, ton chaleureux | 80–250 sig. | Convivial, groupe | 0–3 | Carte OG | 9h–12h / 19h–21h |
| **X (Twitter)** | Thread 3–5 tweets (la sougya en fil) | 280/tweet | Concis, percutant | 1–2 | 1re carte | 9h / 12h / 18h |
| **Threads** | Variante du 1er tweet, plus posée | court | Conversationnel | 0–2 | optionnel | flexible |
| **Bluesky** | Comme X, sans hashtag-spam | 300 | Authentique | 0–1 | optionnel | flexible |
| **WhatsApp/Telegram** (communauté) | Message court + lien | 1–3 lignes | Direct, « le siman de la semaine » | — | — | Vendredi avant Shabbat |

## Gabarits

### LinkedIn
```
[Accroche : une question pratique réelle]
[2–3 phrases : ce que le siman enseigne, en clair]
[1 concept-clé nommé + traduction]
[Pont vers le pratique + « pour le lemaasseh, ton Rav »]
👉 Étudier le siman {N} : https://daattorah.com/oh/{N}/base
#Halakha #Torah #ChoulhanAroukh
```

### Instagram (caption + carrousel)
```
Slide 1 : Titre fort (titre FR du siman)
Slide 2–4 : les concepts-clés / cas pratiques (1 par slide)
Slide 5 : « Étudie les 4 niveaux sur daattorah.com »
Caption : accroche + 1 enseignement + CTA + hashtags
```

### Thread X
```
1/ Accroche : le cas concret (ex. « Confier un colis à un livreur le Shabbat ? »)
2/ Le principe de la source (concept nommé)
3/ La nuance / la mahloket
4/ L'application moderne
5/ « Étudie en profondeur (4 niveaux) 👉 daattorah.com/oh/{N} — pour la pratique, ton Rav. »
```

## URLs canoniques
- Vue d'ensemble : `https://daattorah.com/oh/{N}/`
- Base : `/oh/{N}/base` · Lamdan : `/oh/{N}/lamdan` · Synthèse : `/oh/{N}/synthese` · Daat HaRav : `/oh/{N}/daat-harav`
- Chat IA : `https://daattorah.com/chat.html` · Soutenir : `/soutenir.html`

## Cadence recommandée
- **1 siman / semaine**, étalé : LinkedIn (mar), IG (mer), X thread (jeu), Facebook (ven),
  rappel communauté WhatsApp (ven avant Shabbat). Programmer le tout en 1 session.
