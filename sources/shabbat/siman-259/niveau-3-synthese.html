1. L'Axiome central

Une fois la marmite enfouie vendredi, encore faut-il pouvoir y accéder Shabbat.
Le siman רנ״ט code les questions Shabbat qui surgissent après l'établissement de la הטמנה (sim. 257). Trois axes structurants : (1) les matériaux d'enveloppement sont-ils muktsé ? — selon ייחוד ; (2) la marmite peut-elle être replacée Shabbat ? — selon l'état de la fosse (גומא) ; (3) le tannour scellé peut-il être ouvert et rescellé ? — oui le matin (cuisson achevée), problématique la nuit (גורם בישול). Le siman illustre la cohérence interne du système halakhique : ce qui semble inoffensif (ouvrir un four pour servir) doit être pensé sous l'angle de la cuisson active.

2. Les 3 questions du siman

Question A — Matériaux : muktsé ou non ?

  • גיזי צמר → permis sans ייחוד
  • מוכין (coton, vieux vêtements) → ייחוד ponctuel suffit
  • אבנים, לבנים → ייחוד permanent (לעולם) requis
  • Modernes (alu, serviette, couverture) → généralement permis sans ייחוד spécifique

Question B — Replacer la marmite Shabbat

  • Si la fosse (גומא) est intacte → permis (continuation)
  • Si la fosse est défaite → interdit (= nouvelle הטמנה)
  • Permis לכתחילה de sortir avec intention conditionnelle de replacer

Question C — Tannour scellé d'argile

  • Permis Shabbat de briser le scellement (Mehaber)
  • Avec braises actives — par non-juif (Mehaber) ou Juif avec שינוי (Rama)
  • Resceller seulement le matin (cuisson achevée) — pas la nuit (גורם בישול)

4. Mnémonique — Y-G-S

Y — Yi'houd (ייחוד) : désignation préalable d'un matériau pour la הטמנה. Ponctuel pour les tissus, permanent pour les pierres.

G — Gouma (גומא) : la fosse intacte permet de replacer ; la fosse défaite interdit.

S — Stima (סתימה) : le scellement du tannour. Briser permis Shabbat ; resceller seulement le matin (cuisson achevée).

Pour mémoriser : "Y-G-S pour le siman 259 : Yi'houd avant Shabbat, Gouma intacte pour replacer, Stima rescellée le matin."

Le חידוש majeur du Rama : introduction du concept גורם בישול au Seif Zayin. Ouvrir/fermer un tannour scellé pendant que la cuisson est incomplète = causer la cuisson indirectement. Application directe au four mode Shabbat moderne : ouvrir/fermer la nuit (avant que le tcholent soit cuit כל צרכן) = problématique.

7. 5 pièges à éviter

Piège 1 : Penser qu'une couverture est automatiquement non-muktsé. Vrai pour les couvertures domestiques quotidiennes ; mais une couverture stockée pour usage spécifique peut nécessiter ייחוד. Dans le doute, préparer-la vendredi.
Piège 2 : Mettre des pierres autour de la marmite ad hoc, sans ייחוד permanent. Risque — elles deviennent muktsé. Solution : ne pas le faire, ou prévoir des pierres dédiées au foyer Shabbat.
Piège 3 : Sortir la marmite et tasser le matériau avant de la replacer. Interdit — c'est une nouvelle הטמנה. La fosse doit rester intacte.
Piège 4 : Ouvrir/fermer le four mode Shabbat la nuit alors que le tcholent est encore en cours de cuisson. Risque — sa fermeture cause une accélération de la cuisson = גורם בישול (Rama).
Piège 5 : Avoir des braises actives dans le four et continuer Juif à manipuler sans précautions. Mehaber : non-juif requis. Rama strict : enfant juif ou adulte avec שינוי.

10. Les 5 commandements pratiques du Siman רנ״ט

Pour la conduite quotidienne

  1. Vérifier le statut muktsé du matériau d'enfouissement avant Shabbat — désigner si nécessaire (ייחוד ponctuel pour tissus, permanent pour pierres).
  2. Si muktsé inattendu — utiliser la technique מנער הכיסוי (secouer le couvercle) pour servir sans toucher.
  3. Replacer la marmite Shabbat = OK seulement si la fosse (גומא) est intacte. Sinon attendre la fin du Shabbat.
  4. Tannour scellé / four mode Shabbat — ouvrir/fermer le matin (cuisson achevée) ; problématique la nuit (גורם בישול).
  5. Cohérence avec sim. 257-258 — le sim. 259 termine le triptyque sur la הטמנה (établir / nier / déplacer).
