1. L'Axiome central

La règle des 3 jours comme garde-fou shabbatique.
Le siman רמ״ח codifie une règle d'anticipation : ne pas se mettre, dans les 3 jours qui précèdent Shabbat, dans une situation de voyage qui débordera Shabbat. La règle protège trois biens halakhiques distincts — le oneg Shabbat (Rashi/Rif), l'interdit de tehumin (Yereim/Ramban), et la prévention du pikuah nefesh (Riba/Mahari). Toute la pratique du siman dérive de la pondération de ces 3 biens face aux cas-limites : voyage de mitzva, distance courte, fleuve vs mer salée, caravane terrestre.

2. Les 3 concepts-clés condensés

Concept 1 — la règle des 3 jours (ג' ימים קודם השבת)

  • ✗ Mercredi, jeudi, vendredi (selon Magen Avraham + majorité)
  • ✓ Mercredi (selon Gaon de Vilna seul) — pratique sefarade : strict
  • Compte rétrograde depuis Shabbat (le Shabbat lui-même est inclus dans les "3 jours" selon Gra)

Concept 2 — Mitzva vs Reshut (דבר מצוה / דבר רשות)

  • Mitzva strict (Mehaber) : Aliyah, Torah, hospitalité, mitzva positive
  • Mitzva large (R. Tam, suivi par Rama) : commerce, visite à un ami, parnassah
  • Reshut : tourisme pur (טיול)

Concept 3 — la convention de pause (פוסק עמו שישבות)

  • Convention explicite avec le navigateur de "s'arrêter Shabbat"
  • Selon Rabbi : nécessaire ; selon Rashbag (halakha) : pas nécessaire
  • Mehaber maintient lekhatehilah ; bediavad pas obligatoire
  • Aujourd'hui (services commerciaux) : structurellement impossible

3. Les 3 pirushim — pourquoi 3 jours ?

3 lectures du "pourquoi 3 jours" :
(A) עונג שבת — Rashi, Rif : les 3 premiers jours en mer = mal de mer, pas de oneg Shabbat possible.
(B) איסור תחומין — Yereim, Ramban : si l'eau est <10 tefahim, on est dans le tehum terrestre, risque de sortir des 2000 amot Shabbat.
(C) פיקוח נפש — Riba, Mahari : risque de tempête forçant à violer Shabbat — éviter cette situation par avance.
PirushApplication moderne
(A) OnegVol long-courrier où on est fatigué Shabbat
(B) TehuminBateau en eau peu profonde, train sur rails au sol
(C) SakanaVoyage en zone de guerre, mer agitée, vol risqué

5. Mnémonique — G-M-S

G — Guimel yamim (ג' ימים) : les 3 jours avant Shabbat sont la période sensible. Mercredi-jeudi-vendredi = interdit pour reshut.

M — Mitzvah / Reshut : la grande distinction. Mitzva (large selon R. Tam) → permis. Reshut (tourisme pur) → 3 jours strictement.

S — Sakana / oneg / Shevita : les 3 raisons sous-jacentes (sakana = pikuah nefesh ; oneg = oneg Shabbat ; shevita = קנה שביתה élargit la permission).

Pour mémoriser : "G-M-S — Pendant les 3 jours (G) avant Shabbat, je vérifie Mitzva/Reshut (M), et je réfléchis aux 3 raisons : Sakana, Oneg, Shevita (S)."

8. 5 pièges à éviter

Piège 1 : Croire qu'il suffit d'"avoir Shabbat à bord avec soi" (manger casher, faire kiddoush) pour avoir le droit de partir. Non — la règle est structurelle, elle interdit le voyage en lui-même dans les 3 jours.
Piège 2 : Confondre devar mitzva (large selon R. Tam) avec tout voyage. Le tourisme pur reste reshut, même selon le Rama.
Piège 3 : Penser que la permission Aliyah Eretz Israel s'étend à tout voyage en Israel. Le cas modèle est l'aliyah comme installation. Pour un voyage touristique en Israel, c'est plus subtil.
Piège 4 : Embarquer un jeudi en pensant qu'on est "avant les 3 jours". Jeudi est dans les 3 jours selon le MA (jeudi-vendredi-shabbat = 3 jours).
Piège 5 : Compter sur un éventuel פוסק עמו שישבות avec une compagnie aérienne. Impossible structurellement. Soit on est dans la mitzva (R. Tam), soit on attend.

11. Les commandements pratiques du Siman רמ״ח

Pour la conduite quotidienne

  1. Avant tout voyage débordant Shabbat — distinguer mitzva / reshut. Selon le Rama (R. Tam), presque tout voyage non-touristique est mitzva. Selon Mehaber strict, on garde la définition étroite.
  2. Respecter la règle des 3 jours pour les voyages clairement non-mitzva (croisière de loisir, vacances pures). Embarquer dim-mar, pas merc-jeu-ven.
  3. Aliyah à Eretz Israel = permis tout le temps. C'est la mitzva par excellence (Mehaber Seif Daled).
  4. Vérifier la possibilité d'arriver avant Shabbat. Cas Tsour-Tsidon = trajet ≤1 jour permis vendredi matin.
  5. Honorer Shabbat à bord — kiddoush, prières, repas dignes — même en avion ou en bateau. Et consulter son Rav pour les cas-limites (long-courriers, fuseaux horaires, urgences professionnelles).
