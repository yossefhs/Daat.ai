1. L'Axiome central

La femme allume la lumière de Shabbat — et entre en Shabbat avec elle.
Le siman רס״ג code la mitsva centrale du foyer juif. Trois axes : (1) Mitsva universelle (hommes et femmes obligés, même les pauvres), avec priorité féminine ; (2) Acte technique (2 mèches Zakhor/Shamor, brakha avec yeux couverts, position des bougies) ; (3) Acceptation — חידוש cardinal du Bahag : l'allumage est en lui-même une acceptation halakhique de Shabbat. La femme entre dans Shabbat à l'instant où elle bénit. Cette synthèse unique entre physique (la flamme) et spirituel (l'entrée en sainteté) fait du siman 263 le pivot central des Hilkhot Shabbat.

2. Les 3 axes du siman

Axe A — Mitsva universelle (Seifim 1-3)

  • Belle bougie ; 2 mèches Zakhor/Shamor ; 3-4 OK (Rama)
  • Hommes et femmes obligés ; même un pauvre mendie pour avoir de l'huile
  • Femmes prioritaires ; nér Shabbat avant nér Hanouka (shalom bayit)

Axe B — Acte technique (Seifim 4-9)

  • Pas trop tôt, pas trop tard (sauf si on accepte Shabbat tôt ≥ פלג המנחה)
  • Brakha + minhag des yeux couverts
  • Étudiant en yeshiva : allume + bénit dans sa chambre
  • Invité : פרוטה pour s'associer
  • Plusieurs baalei batim : chacun bénit
  • Bougies trop courtes (s'éteignent avant la nuit) = ברכה לבטלה

Axe C — Acceptation (Seifim 10-17)

  • חידוש Bahag : allumage = acceptation pour la femme qui allume
  • Conditionnement "dans le cœur" possible (Mordechai)
  • Reste de la maison : libre jusqu'à Barekhu (Rama)
  • Tefilat Maariv tôt = acceptation
  • Voyageur dans une ville déjà acceptée = entraîné
  • Erreur de jour nuageux : communauté pas re-prier ; individu doit re-prier
  • Possibilité de demander à un autre Juif (qui n'a pas accepté) une mélakha

4. Mnémonique — N-B-Q

N — Néir (נֵר) : la bougie. 2 mèches minimum (Zakhor/Shamor) ; 3 si oubli antérieur ; +1 par enfant en Habad. Femme prioritaire.

B — Brakha (בְּרָכָה) : minhag des yeux couverts — allumer → couvrir → bénir → découvrir → regarder.

Q — Qabalat (קַבָּלַת שַׁבָּת) : l'allumage = acceptation pour la femme (Bahag). תנאי בלב possible.

Pour mémoriser : "N-B-Q pour le siman 263 : Néir 2 mèches minimum, Brakha avec yeux couverts, Qabalat par allumage."

7. 5 pièges à éviter

Piège 1 : Allumer puis vouloir continuer un acte profane (texto, fermer le frigo). Interdit selon Rama (acceptation par allumage). Solution : conditionner mentalement avant d'allumer (rare).
Piège 2 : Allumer dans le salon mais manger dans la salle à manger. Risque ברכה לבטלה si les bougies sont courtes (s'éteignent avant la nuit). Soit utiliser bougies longues, soit allumer là où on mange.
Piège 3 : Allumer puis déplacer les bougies vers la table. Faux selon Rama — l'allumage doit se faire au lieu où elles resteront. Position définitive avant l'allumage.
Piège 4 : Étudiant à la yeshiva qui pense que ses parents allument pour lui à la maison. Faux — il doit allumer + bénir dans sa propre chambre.
Piège 5 : Pauvreté qui empêche d'avoir des bougies → omettre la mitsva. Faux — le Mehaber ordonne de mendier aux portes pour avoir de l'huile. La mitsva est universelle, sans excuse de pauvreté.

10. Les 5 commandements pratiques du Siman רס״ג

Pour la conduite quotidienne

  1. Allumer 2 bougies minimum (Zakhor/Shamor) — 3 si oubli antérieur, +1 par enfant en Habad. Femme prioritaire.
  2. Brakha avec yeux couverts — allumer → couvrir → bénir → découvrir → regarder → Mizmor.
  3. Acceptation par allumage — la femme entre en Shabbat à l'instant où elle bénit. Conditionnement préalable possible mais exceptionnel.
  4. Étudiant / voyageur — allumer + bénir dans la chambre dédiée ; sinon פרוטה pour s'associer.
  5. Universalité — la mitsva est obligatoire pour tous, même les pauvres mendient pour avoir de l'huile.
