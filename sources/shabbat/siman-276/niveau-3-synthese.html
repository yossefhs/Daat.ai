1. L'Axiome central

Le Siman רע״ו en une phrase.
"אמירה לעכו״ם" (demander à un non-juif) — interdit dérabanan général Shabbat. Si le non-juif allume "pour le juif", le bénéfice est interdit à tous les juifs. Exceptions : pour soi-même, malade, enfants, pays froids. Heter du Rama (Itour) pour sé'oudat mitsva — toléré mais débattu.

4. Arbre de décision pratique

Q1 : Le non-juif a-t-il allumé pour le juif ? → OUI : interdit (sauf exceptions).
↓
Q2 : Pour lui-même, malade ou enfant juif ? → permis (s.1).
↓
Q3 : Repas mixte ? Majorité non-juifs : permis. Majorité juifs ou égalité : interdit (s.2).
↓
Q4 : Sé'oudat mitsva (mariage, milah) ? Rama : tolérance Itour. Ailleurs : interdit.
↓
Q5 : Pays froids — chauffage par non-juif ? Pour enfants/froid extrême : permis (s.5).

5. Le critère בִּשְׁבִיל יִשְׂרָאֵל — la charnière du siman

Le siman רע״ו ne se résout pas en une liste de cas permis et interdits : tout dépend d'une seule question — le feu a-t-il été allumé בִּשְׁבִיל יִשְׂרָאֵל, « pour le juif » ? C'est la charnière qui commande tout le reste, et c'est aussi le point où l'on se trompe le plus.

Allumé pour le juif → interdit à tous. Si le non-juif allume en faveur d'un juif, le bénéfice est défendu non seulement à ce juif, mais à tous les juifs présents. Le profit (הֲנָאָה) tiré d'une mélakha faite pour soi est l'objet de l'interdit.
↓
Allumé pour le non-juif lui-même → permis. S'il allume pour son propre usage, le juif peut en profiter incidemment — aucune אֲמִירָה, aucune intention en faveur du juif.
↓
Cas mixte → on tranche par la majorité. Repas où juifs et non-juifs sont attablés : majorité de non-juifs → réputé fait pour eux, permis ; majorité de juifs ou égalité → réputé pour les juifs, interdit (s.2).
Le piège central — l'allumage « sans demande ». On croit volontiers qu'en l'absence d'אֲמִירָה explicite tout est permis. Faux. Si le contexte suppose que le feu est destiné aux juifs — un hôtel juif, une maisonnée juive — le non-juif est réputé avoir agi « pour le juif » même sans un mot. C'est pourquoi le Rama (s.4) recommande de protester : la protestation requalifie l'acte en « pas pour le juif » et préserve la permission.
Le seul vrai assouplissement. Là où l'allumage est intrinsèquement « pour le juif », une seule porte reste ouverte : le חוֹלֶה ou le קָטָן — le malade et l'enfant juifs — pour qui le non-juif est autorisé. Le froid extrême, où « tous sont malades », étend cette même logique. Le heter Itour pour une sé'oudat mitsva (Rama) reste, lui, débattu et minoritaire — le critère בִּשְׁבִיל יִשְׂרָאֵל n'y est pas levé, seulement toléré.

6. Mnémonique — B.M.I.C.

B — Bishvil Israel (בשביל ישראל) : critère central. Si oui = interdit.

M — Mahaleh/Malade (חולה) : exception. Pour malade = permis.

I — Itour (heter du Rama) : sé'oudat mitsva, mariage, milah — toléré.

C — Cold (קר גדול) : froid extrême = "tous malades" — chauffage permis.

7. Les 4 pièges à éviter

Piège 1 — Demander explicitement au non-juif d'allumer pour le repas de Shabbat. Interdit (s.2) sauf sé'oudat mitsva selon Rama. La plupart des poskim s'opposent même au heter Itour.
Piège 2 — Bénéficier de la lumière du non-juif quand "personne ne l'a demandé". Si l'usage suppose que c'est pour les juifs (hôtel juif, par exemple) — interdit même sans demande explicite.
Piège 3 — Confondre "feu pour le froid extrême" avec "feu pour confort". Seul le froid grand (où "tous sont malades") justifie l'heter (s.5). Pas pour adultes par confort.
Piège 4 — Ne pas protester contre le non-juif qui allume. Le Rama (s.4) recommande de protester. Cela renforce le statut "pas pour le juif".

SituationConduite

Hôpital — non-juif allume pour patientPermis (s.1 exception malade). Tous les patients juifs bénéficient.

Bâtiment à chauffage central allumé par concierge non-juifSi pour tous les habitants (mixte) — selon seif 2. Pays froid + enfants : permis (s.5).
"Shabbos goy" employé pour services ShabbatDoit faire de propre initiative ou être préemployé. אמירה directe interdite.

10. Les 5 commandements pratiques du Siman רע״ו

🕯️ La règle de la bougie allumée par non-juif — en 5 commandements

  1. Si pour le juif → interdit à tous les juifs d'en bénéficier (s.1).
  2. Exceptions : pour soi-même, malade juif, enfants juifs — permis.
  3. Repas mixte : majorité non-juifs = permis. Majorité juifs = interdit (s.2).
  4. Heter Itour (Rama) : mariage/milah — toléré mais à utiliser avec retenue.
  5. Pays froids : chauffage pour enfants/froid extrême = permis (s.5).

→ "Shabbos goy" et automatisations modernes : voir siman 277 et consultations rabbiniques.
