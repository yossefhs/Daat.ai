1. היסוד: 4 מנגנוני העברת הטעם

נקודת המוצא:

סימן קה משיב על שאלה אחת — באיזה דרך עובר טעם האיסור אל ההיתר? — ולכל אחת נותן את השיעור שלה. ללא בישול בקדירה, יש ארבעה מנגנונים: הכבוש, שבו 24 שעות בצונן « הֲרֵי הוּא כִּמְבֻשָּׁל » ; החום של כלי ראשון ש« יָד סוֹלֶדֶת בּוֹ » ; הצלי סמוך לאש ; והמליחה, שבה מאכל מלוח מדי לאוכלו « דִּינוֹ כְּרוֹתֵחַ ». לכל דרך שיעורה: הדחה בעלמא, קליפה, עובי אצבע, או ביטול גמור בששים.

2. 3 שאלות־הרפלקס

■ באיזה מנגנון? (כבוש / חום / צלי / מליחה) — האם המגע נעשה בכבוש 24 שעות (סעיף א), בחום כלי ראשון (סעיף ב-ג), בצלי (סעיף ד-ו), או במליחה (סעיף ט-יד)? לכל מנגנון שיעורו.
↓ מביטים בטמפרטורה
■ חם או צונן? (תתאה גבר) — ״התחתון גובר״: איסור חם למטה (או אף צונן למטה) → הכל אסור ; חם למעלה / צונן למטה → רק כדי קליפה. כלל זה שולט במגע שבחום (סעיף ג, ו) ולחלק מהפוסקים אף במליחה (סעיף יא).
↓ מביטים בשומן
■ האם יש שומן? (כחוש / שמן · פעפוע) — כחוש בלא כוח להפעפע → רק כדי נטילה. שמן המפעפע בכולו → צריך 60 כנגד השומן, ואף עם 60, נטילת מקום. ואין אנו בקיאים להבחין: ממנהג, אומדים עד 60 (סעיף ה, ט).

⚖ עיקרון כבוש כמבושל (סעיף א)

איסור הנשרה עם היתר 24 שעות בצונן (מעת לעת) ״כבוש״, והרי הוא כמבושל: הכל אסור. פחות מכאן → הדחה סגי. בציר (מלח) או בחומץ, השיעור מתקצר ל« כְּדֵי שֶׁיַּרְתִּיחַ » ; פחות מכאן → רק כדי קליפה. רמ״א: כבישת התחתון מפעפעת למעלה, לכן אף מה שחוץ לנוזל אסור (ויש מקילין) ; וספק כבוש אסור, חוץ מבשר בחלב שמקילים, כי מן התורה רק בישול ממש אוסר.

4. 5 כללי הזהב

  1. « כבוש כמבושל ». 24 שעות בצונן = כמבושל (הכל אסור) ; פחות מכאן, הדחה סגי ; בציר/חומץ, השיעור יורד לכדי שירתיח. ספק כבוש אסור, חוץ מבשר בחלב (מחבר + רמ״א סעיף א).
  2. « יד סולדת בו » מכריע. כלי ראשון (היד סולדת) מבשל ואוסר את הכל ; כלי שני אינו מבשל → בדיעבד הדחה סגי (מחבר סעיף ב).
  3. « תתאה גבר » — התחתון גובר. התחתון (חם או צונן) מכריע: חם למטה → הכל אסור ; צונן למטה → רק כדי קליפה (מחבר סעיף ג, ו).
  4. צלי = כדי נטילה ; השומן מפעפע (פעפוע) = 60. צלי כחוש אוסר רק עובי אצבע ; השומן (חלב / שומן) מפעפע בכולו → 60, ואף עם 60, נטילת מקום (מחבר סעיף ד-ה).
  5. « מליח כרותח » ; ו« אין הנאסר אוסר יותר מן האוסרו ». מאכל מלוח מדי דינו כרותח ; המנהג: לאמוד כל מליחה בששים. אך הנאסר (המלח) אינו אוסר יותר מן האוסרו (הדם): 60 כנגד המלח סגי (מחבר סעיף ט ; רמ״א סעיף יד).

6. 4 המלכודות הקלאסיות

❌ מלכודת 1 — לחשוב שכל כבישה אוסרת את הכל: רק 24 שעות בצונן (מעת לעת) עושה ״כמבושל״. פחות מכאן, הדחה סגי. בציר או חומץ, הזמן מתקצר ל« כְּדֵי שֶׁיַּרְתִּיחַ », אך פחות מכאן → רק כדי קליפה, לא הכל. וספק כבוש אסור — חוץ מבשר בחלב, שמן התורה רק בישול ממש אוסר (מחבר + רמ״א סעיף א).
❌ מלכודת 2 — לבלבל בין כלי ראשון לכלי שני: רק כלי ראשון ש« יָד סוֹלֶדֶת בּוֹ » מבשל ואוסר את הכל. כלי שני אינו מבשל: נזהרים לכתחילה (יש המצריך קליפה), אך בדיעבד הדחה סגי, בלא קליפה (מחבר סעיף ב). אין לדון כף שנשאבה מקדירה (כלי שני) כקדירה עצמה (כלי ראשון).
❌ מלכודת 3 — לשכוח את השומן (פעפוע) בצלי: צלי כחוש אוסר רק כדי נטילה ; אך משיש שומן (חלב / שומן), הוא מפעפע בכולו → צריך 60, ואף עם 60, נטילת מקום (מקום המגע). וכיון שאין אנו בקיאים להבחין כחוש/שמן, המנהג לאסור עד 60 בכל אופן — חוץ מאיסור בלא שום שומן (מחבר + רמ״א סעיף ה).
❌ מלכודת 4 — להרחיב מליחה לכלים, ולשכוח « אין הנאסר אוסר יותר מן האוסרו »: המליח אינו כרותח כדי להוציא מכלי את הבלוע בו → בדיעבד מותר (לכתחילה אסור, סעיף יב) ; והמלח או התבלין יבשים אינם בולעים מן הכלי (סעיף יג). וסוף סוף, מלח ספוג דם שנתן בקדירה: 60 כנגד המלח סגי, כי המלח אינו אסור אלא מחמת הדם — ו״אין הנאסר אוסר יותר מן האוסרו״ (סעיף יד, מפנה לסימן סט).

להלכה למעשה, היוועץ ברבך.

7. סיכום 14 הסעיפים — שורה לכל אחד

סעיףנושאהעיקר
1כבוש כמבושלכבוש 24 שעות בצונן (מעת לעת) = כמבושל, הכל אסור ; פחות מכאן → הדחה. בציר/חומץ: כדי שירתיח → כמבושל, אחרת כדי קליפה. רמ״א: אף חוץ לנוזל אסור (התחתון מפעפע) ; ספק כבוש אסור, חוץ מבשר בחלב (מפנה לסימן ע).
2כלי ראשון / כלי שניכלי ראשון יד סולדת בו מבשל ואוסר את הכל. כלי שני אינו מבשל ; יש אומרים שמוציא/בולע כדי קליפה → להיזהר לכתחילה, אך בדיעבד מותר בלא קליפה, הדחה סגי (מפנה לסימנים סח, צב, צה).
3תתאה גבר (התחתון גובר)איסור חם, או אף צונן, בהיתר חם של כלי ראשון → הכל אסור. חם למעלה / צונן למטה → רק כדי קליפה, אף שהחם שלמעלה הוא האיסור. רמ״א: אותו דין בין כלי למאכל (מפנה לסימן צד).
4רוטב מול צלי = כדי נטילהאיסור גמור כשנפל לתבשיל עם רוטב (הרוטב מוליך את הפליטה). על צלי סמוך לאש → רק כדי נטילה (עובי אצבע). בתוך הרוטב, או ניער/כיסה → הטעם מתפשט בכל.
5כחוש מול שמן ; פעפועכחוש → כדי נטילה. גדי שמן צלוי עם חלבו, בלא 60 → הכל אסור (השומן מפעפע בכולו) ; אף עם 60 → נטילת מקום. כל מבושל בלא רוטב או אפוי = כצלי (רמ״א). אין אנו בקיאים כחוש/שמן → 60 בכל.
6חם / צונן בצליאף בצלי התחתון גובר: חם על צונן → כדי קליפה ; צונן על חם, בלא 60 כנגד האיסור → הכל אסור.
7איסור מחמת עצמו מול בלועחתיכה אינה אוסרת חברתה במגע אלא כשאיסורה מחמת עצמה (נבילה, בשר בחלב). איסור בלוע בלבד (בלע) אינו אוסר — חוץ אם בלע שומן המפעפע. רמ״א: כלי שבלע אוסר, אף איסור בלא שומן.
8הכוליאכוליא צלויה בחלבה → רק כדי קליפה, כי הקרום מפסיק. רמ״א: יש אוסרים וכן המנהג ; ואם נתבשל כך, הכוליא נעשית נבילה → 60 כנגד כולה.
9מליח כרותח (המליחה)מליח שאינו נאכל מחמת מלחו = כרותח → קליפה. חלב ממש → 60. חתיכות מלוחות יחד: אין מצטרפות (החלב אינו מפעפע בלא רוטב). אחת נגעה ואין יודעים איזו → כולן מותרות (חד בתרי בטיל). רמ״א: מנהג לאמוד כל מליחה בששים (אין אנו בקיאים) ; איסור בלא שומן → רק קליפה.
10מליח / תפלשניהם מלוחים, או איסור מלוח / היתר תפל → אסור. אך היתר מלוח / איסור תפל → הדחה סגי (מפנה לסימן ע). רמ״א: יש אוסרים אם נוגעים ; מקילים בהפסד.
11עליון / תחתון במליחההאיסור השמן האוסר עד 60 — רק כשהאיסור המלוח למטה וההיתר התפל למעלה (תתאה גבר) ; להיפך → רק כדי קליפה. רמ״א: יש חולקין — במליחה אין הפרש עליון/תחתון, וכן המנהג.
12אין מליחה לכליםגבינות שנעשו בדפוסי נכרים, אף שנמלחו → מותרות. רמ״א: וכן היתר שנמלח בכלי איסור, כי המליח אינו מוציא מן הכלי את הבלוע ; אך בדיעבד בלבד, לכתחילה אסור.
13מלח / תבלין יבשיםמלח או תבלין יבשים שהיו בקערת בשר → מותר ליתנם בחלב. רמ״א: וכן אם היו בכלי איסור, כי יבשים אינם בולעים, ובלבד שהכלי נקי ; והמחמיר לכתחילה, תבוא עליו ברכה.
14אין הנאסר אוסר יותר מן האוסרומלח ספוג דם, או בשר מלוח שלא הודח, שנתן בקדירה → אם יש 60 כנגד המלח, מותר. רמ״א: אף שהמלח נותן עוד טעם, אינו אסור אלא מחמת הדם ; הנאסר אינו אוסר יותר מן האוסרו (מפנה לסימן סט).

⚖ הרפלקס ב־3 שאלות

  1. באיזה מנגנון? כבוש (24 שעות), חום (כלי ראשון), צלי או מליחה — לכל אחד שיעורו: הדחה / קליפה / נטילה / 60 / הכל אסור.
  2. חם או צונן? תתאה גבר: התחתון גובר. חם למטה → הכל אסור ; צונן למטה → רק כדי קליפה.
  3. האם יש שומן? כחוש → נטילה ; שומן המפעפע (פעפוע) → 60 + נטילת מקום.
להלכה למעשה, היוועץ ברבך.
