1. היסוד: אין מבטלין איסור לכתחילה

נקודת המוצא:

סימן צט מאריך בחשבון הביטול בששים: אילו דברים מצטרפים עם ההיתר לבטל, כיצד משערים את התערובת, ו — וזהו לב הסימן — האיסור לבטל איסור לכתחילה. המחבר (סעיף ה) פוסק: « אֵין מְבַטְּלִין אִסּוּר לְכַתְּחִלָּה » — אפילו נפל לתוך היתר שאין בו שיעור לבטלו, אין מוסיפין עליו היתר כדי להגיע לששים. עבר ועשה: בשוגג → מותר ; במזיד → אסור למבטל ולמי שנתבטל בשבילו.

2. 3 שאלות־הרפלקס

■ מה מצטרף? (מצטרף) — עצמות האיסור מצטרפות עם ההיתר לבטל ; אך המוח מצטרף עם האיסור, וגוף הקדירה אינו מצטרף לא לזה ולא לזה (סעיף א). חי → עם ההיתר ; נתבשל לבדו תחילה → עם האיסור (סעיף ב).
↓ מביטים בשיעור
■ כיצד משערים? (כמו שבא לפנינו) — משערים רוטב, קיפה וחתיכות כמו שהם לפנינו. במין בשאינו מינו: כמו שהם. במין במינו: משערים גם מה שבלעה הקדירה. אך מה שכלה ואבד מחמת האור (כלה מחמת האור) אינו מצטרף (סעיף ד).
↓ מביטים מי ביטל
■ מי ביטל, וכיצד? (שוגג / מזיד) — אין מוסיפין היתר לכתחילה. עבר: שוגג → מותר ; מזיד → אסור למבטל ולמי שנתבטל בשבילו (אסור למוכרו ליהודי), ומותר לאחרים (סעיף ה).

⚖ חוזר וניעור (סעיף ו)

איסור שכבר נתבטל (היו ששים כנגדו) שמוסיפים עליו אחר כך מן האיסור הראשון → הוא חוזר וניעור ונאסר שוב, בין מין במינו בין מין בשאינו מינו, יבש או לח, בין שנודע בינתיים בין שלא נודע (רמ״א). אך כזית חלב שנפל למים ונתבטל בששים, ואחר כך נפל מן המים לקדירת בשר → מותר, אף שאין ששים בבשר כנגד החלב, הואיל וכבר נתבטל במים.

4. 5 כללי הזהב

  1. « עצמות מצטרפין לבטל ». עצמות האיסור (שאינן נאכלות) מצטרפות עם ההיתר לבטל ; המוח מצטרף עם האיסור, וגוף הקדירה אינו מצטרף לא לזה ולא לזה (מחבר סעיף א).
  2. חי → היתר ; נתבשל לבדו → איסור. נפל חי, העצם מצטרפת עם ההיתר ; נתבשל לבדו תחילה, בלעה מן הנבילה → מצטרפת עם האיסור (מחבר סעיף ב).
  3. « משערין כמו שבא לפנינו ». משערים רוטב, קיפה וחתיכות כמו שהם ; במין במינו מוסיפים את הבלוע, אך כלה מחמת האור אינו מצטרף (מחבר סעיף ד).
  4. « אין מבטלין איסור לכתחילה ». אין מוסיפין היתר לכתחילה ; עבר: שוגג מותר, מזיד אסור למבטל ולמי שנתבטל בשבילו (מחבר סעיף ה).
  5. « חוזר וניעור ». הוספת איסור ראשון לתערובת שכבר נתבטלה מעוררת אותה ; אך הנתבטל העובר להיתר חדש (חלב→מים→בשר) אינו חוזר וניעור (רמ״א סעיף ו).

6. 4 המלכודות הקלאסיות

❌ מלכודת 1 — לצרף את המוח עם ההיתר: עצמות האיסור (שאינן נאכלות) מצטרפות עם ההיתר, אך המוח שבתוכן הוא מן האיסור ומצטרף עם האיסור (סעיף א). הש״ך (ס״ק א) מדייק: עצמות רכות (עם מוח / לחלוחית) מצטרפות עם האיסור ; עצמות יבשות או קליפות ביצים, אף של האיסור, מצטרפות עם ההיתר.
❌ מלכודת 2 — לשכוח שהנתבשל לבדו משנה הכל: כל עוד חתיכת האיסור נפלה חיה, עצמותיה מצטרפות עם ההיתר. אך אם נתבשלה לבדה תחילה ואחר כך נפלה לקדירה, עצמותיה בלעו מן הנבילה באותו בישול → ומעתה הן מצטרפות עם האיסור, לא עם ההיתר (סעיף ב). אין לשער בלי לדעת אם האיסור נתבשל לבדו קודם.
❌ מלכודת 3 — לבלבל בין שוגג ומזיד: « אין מבטלין איסור לכתחילה » אוסר להוסיף היתר כדי לבטל. אם עבר: בשוגג → מותר ; במזיד → אסור למי שביטל (אם שלו) ולמי שנתבטל בשבילו (ואסור למכרו ליהודי אחר), אך מותר לאחרים. הט״ז (ס״ק י) מדייק: « בשבילו » רק אם ידע והיה ניחא לו.
❌ מלכודת 4 — לקרוא לא נכון את חוזר וניעור: מעוררים (חוזר וניעור) את מה שנתבטל רק כשמוסיפים מן האיסור הראשון (מן האיסור הראשון) — איסור חדש מאותו מין (סעיף ו). לעומת זאת, הנתבטל העובר להיתר חדש — כזית חלב שנתבטל במים, ואחר כך נפל לבשר — אינו חוזר וניעור, שכבר נתבטל. ואיסור אחר המבטל את חברו שייך לסימן צח, לא להתעוררות זו.

להלכה למעשה, היוועץ ברבך.

7. סיכום 7 הסעיפים — שורה לכל אחד

סעיףנושאהעיקר
1העצמות מצטרפיןחתיכת נבילה (בשר + עצמות) שנפלה לקדירת היתר: עצמות האיסור מצטרפות עם ההיתר לבטל (וכל שכן עצמות ההיתר). אך המוח מצטרף עם האיסור ; וגוף הקדירה אינו מצטרף לא לזה ולא לזה. רמ״א: יש מחמירים שלא לצרף עצמות האיסור ; ובמקום הפסד סומכים על המקילים.
2חי / מבושל בפני עצמוכל זה כשחתיכת הנבילה נפלה חיה (חַי) ; אך אם נתבשלה תחילה לבדה ואחר כך נפלה → עצמותיה מצטרפות עם האיסור, שכן בלעו בשר נבילה בבישול שלבד.
3שאר איסורים ; חתיכה נעשית נבילהבשאר איסורים (חוץ מבשר בחלב), חתיכה הבלועה מאיסור מצטרפת לבטל את האיסור. רמ״א: אין נוהגין כן, שאנו אומרים חתיכה נעשית נבילה בכל האיסורים (עיין סימן צב).
4כמו שבא לפנינו ; מין במינומשערים ברוטב, בקיפה (השקעים שבקרקעית) ובחתיכות, כמו שהם לפנינו (כמו שבא לפנינו), אף שהיה יותר היתר בתחילה. וזה במין בשאינו מינו ; אך במין במינו משערים גם מה שבלעה הקדירה (כאילו הוא בעין). אך מה שכלה ואבד מחמת האור (כלה מחמת האור) אינו מצטרף.
5אין מבטלין ; שוגג / מזידאין מבטלין איסור לכתחילה ; אפילו נפל לתוך היתר שאין בו שיעור, אין מוסיפין היתר. עבר: שוגג → מותר ; מזיד → אסור למבטל ולמי שנתבטל בשבילו (אסור למכרו ליהודי), אך מותר לאחרים. רמ״א: ודווקא ביבש ביבש (או לח בלח למי שאינו אומר חנ״נ) ; חתיכה הבלועה מאיסור — ההוספה אינה מועילה (חנ״נ, רשב״א) ; ואין נוהגין לחלק בין נודע ללא נודע.
6איסור דרבנן ; חוזר וניעוראיסור דרבנן: אין מערבו ביד ; במזיד → אסור ; נפל מעצמו בלי ששים → מרבה עליו ומבטל. רמ״א: יש אומרים שאין מבטלין דרבנן אף הוא — וכן המנהג. חוזר וניעור: הוספת איסור ראשון לתערובת שנתבטלה → חוזר וניעור (מין במינו או בשאינו מינו). אך חלב שנתבטל במים, ואחר כך נפל לבשר → מותר, שכבר נתבטל.
7משהו בכלי ; שימוש בשפעמעט איסור בלוע בכלי כשר: אם דרך הכלי לשמש בשפע (בשפע) של היתר → מותר לכתחילה, שהאיסור מועט ואי אפשר לבוא לידי נתינת טעם. כך קדירה, קנקנים → מותר לכתחילה אף בן יומו. אך כלי שלפעמים משמש בדבר מועט (קערה) → אסור אף בשפע, גזירה שמא ישתמש בה בדבר מועט.

  1. מה מצטרף? עצמות האיסור → היתר ; מוח → איסור ; נתבשל לבדו תחילה → איסור ; קדירה → לא לזה ולא לזה.
  2. כיצד משערים? כמו שבא לפנינו ; במין במינו מוסיפים הבלוע ; כלה מחמת האור אינו מצטרף.
  3. מי ביטל, וההתעוררות? שוגג מותר / מזיד אסור ; איסור ראשון שנוסף → חוזר וניעור ; משהו בכלי בשפע → מותר.
להלכה למעשה, היוועץ ברבך.
