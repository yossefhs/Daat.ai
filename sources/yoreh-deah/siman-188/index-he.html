סימן קפ״ח — מראות הדם הטמאים והטהורים

הכל תלוי במראה : מן התורה אין מטמא אלא בחמישה מראות ; חכמים החמירו (מחשש לטעות בין דם לדם) ואסרו כל הנוטה לאדמימות, והכשירו כל שאין לספקו באדמימות. אדום ושחור → טמא ; לבן וירוק → טהור. מכאן ההלכה דהאידנא : אין דנין בעצמן, אלא מראין את הבדיקה למורה הוראה ; הנאמנות, התליה במכה ובדיקת השרייה של מפלת (שולחן ערוך, יורה דעה קפ״ח — ו׳ סעיפים). עניין חמור: פנייה אל הרב.

דַּם הַנִּדָּה אֵינוֹ מְטַמֵּא אֶלָּא בְּחֲמִשָּׁה מַרְאוֹת מִן הַתּוֹרָה ; וְכָל מַרְאֵה אָדֹם — בֵּין כֵּהֶה בֵּין עָמֹק — טָמֵא, וְכֵן כָּל מַרְאֵה שָׁחֹר ; וְאֵינוֹ טָהוֹר אֶלָּא הַלָּבָן וְהַיָּרֹק, אֲפִלּוּ כְּמַרְאֵה הַשַּׁעֲוָה וְהַזָּהָב, וְכָל שֶׁכֵּן כְּמַרְאֵה הַכַּרְתִּי וְהָעֵשֶׂב — טְהוֹרָה.

הכל תלוי במראה. מן התורה אין דם הנדה מטמא אלא בחמישה מראות ; אך חכמים החמירו. כל מראה אדום — כהה או עמוק — טמא, וכן כל מראה שחור ; ואינו טהור אלא הלבן והירוק — אפילו כמראה השעוה והזהב, וכל שכן כמראה הכרתי והעשב.

ארבע רמות הלימוד

רמה 01

רמת המתחיל

בסיס — מתחיל ובינוני

לשון ו׳ הסעיפים עם ביאור בעברית. המראות (אדום ושחור → טמא, לבן וירוק → טהור), ההלכה להראות את הבדיקה למורה הוראה, נאמנות « כזה ראיתי », השפופרת והחתיכה, התליה במכה ובדיקת השרייה של מפלת — מבוארים בכובד ראש ובצניעות, עם מקרים מעשיים הפונים אל הרב.

רמה 02

רמת הלמדן

למדן — תלמיד חכם

פלפול מעמיק: ה׳ מראות דאורייתא וגזרת חכמים (ש״ך ס״ק א — « אסרו כל הנוטה לאדמימות, הכשירו כל שאין לספקו באדמימות ») ; ארבעת האדומים והשחור ; מחלוקת הירוק (מהר״ם מינץ, של״ה, פת״ש ס״ק ב) ; חכמת הראייה ובזמן הזה (יום / לילה, לח / יבש, פת״ש ס״ק א וס״ק ג) ; התליה במכה / חתיכה ונעקר המקור (סעיפים ג-ה) ; השפופרת והבית החיצון ; בדיקת השרייה כבירור טבע הדבר (דם מול בריה, סעיפים ד-ו).

רמה 03

חזרה וסיכום

סיכום — חזרה

טבלאות השוואה (אדום / שחור → טמא, לבן / ירוק → טהור ; לח / יבש ; שפופרת / חתיכה / נעקר מקור ; שרייה של מפלת), כללי זהב, מכשולים נפוצים ומראי מקומות (סים. קפ״ז, ק״צ, קצ״ד, קצ״ו) ; שינון ו׳ סעיפי מראות הדם, ותמיד הפנייה אל הרב במראה ספק.

רמה 04

דעת הרב והלכה למעשה

רמה 4 — דעת הרב והלכה למעשה

שני חלקים: דרך חב״ד ומסורת הצמח צדק מליובאוויטש (דעת הרב, בעיקרון), ואחר כך ההלכה למעשה לפוסקים — בית יוסף, רמ״א, ש״ך, ט״ז, סדרי טהרה, חכמת אדם, ערוך השולחן, טהרת הבית, שבט הלוי, בדי השולחן — תמיד תוך פנייה אל הרב. הערת שיטה: אין מציינים אלא דעות אמיתיות ; ובהיעדרן נאחזים בעיקרון (ומבחינים בין הצמח צדק מליובאוויטש לבין « הצמח צדק » הקדמון, ר׳ קרוכמל, שהביא הפתחי תשובה ס״ק ז).

📖 ללמוד

שאלות נפוצות — סימן קפ״ח

אילו מראות דם מטמאים, ואילו טהורים?

מן התורה אין מטמא אלא בחמישה מראות ; אך חכמים, מחשש לטעות בין דם לדם, החמירו ואסרו כל הנוטה לאדמימות, והכשירו כל שאין לספקו באדמימות (ש״ך ס״ק א). למעשה : כל מראה אדום (כהה או עמוק) וכל מראה שחור → טמא ; ואינו טהור אלא הלבן והירוק — אפילו כמראה השעוה והזהב, וכל שכן כמראה הכרתי והעשב (שו״ע קפ״ח:א). הגבול (חום, בז׳, צהוב…) דק, ואין דנין אותו בעצמן : מראין את הבדיקה לרב.

מדוע בזמן הזה מראין את הבדיקה לרב ואין דנין בעצמן?

משום שהבחנת גוני האדמימות היא חכמת הראייה שאיננו בקיאין בה עוד. האחרונים הדגישו כמה המראה עלול להטעות — לפי יום או לילה, לפי שהכתם עדיין לח או כבר יבש (פתחי תשובה ס״ק א וס״ק ג) — והשולחן ערוך עצמו מורה (קפ״ח:ב) שהאשה אינה נאמנת לסמוך על עצמה במקום שיש לחוש. ההלכה המרכזית דהאידנא : כתם ספק על בגד הבדיקה אינו נידון בעצמן ; מראין אותו למורה הוראה הבוחן את מראהו, והוא המכריע.

מהן הנאמנות, התליה במכה ובדיקת השרייה של מפלת?

נאמנות (קפ״ח:ב) : האשה נאמנת לומר « כזה ראיתי ואבדתיו » אם הוא לבן או ירוק → טהור ; אבל אם מביאה דם המוחזק טמא ואומרת שחכם טיהר כיוצא בו — אין סומכין עליה : צריך להראותו. תליה במכה (קפ״ח:ג-ה) : דם שיצא דרך שפופרת, או שבתוך חתיכה, או כשהמקור נעקר, → טהורה, שאין זו דרך ראייתה ותולין במכה (רמ״א). בדיקת השרייה (קפ״ח:ד-ו) : מפלת כעין בריה (קליפות, שערות, יבחושים אדומים) טמאה אם, בשרייה מעת לעת במים פושרים, היא נמוחה ; ואם לאו — יבשה ובלא שום דם — טהורה. עניין חמור : כל אחד מהם נחתך עם הרב שלך (ועיין סים. קצ״ד).
