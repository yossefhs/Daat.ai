1. היסוד: להבטיח כשרות של מאכל שנמסר ביד עכו״ם

נקודת המוצא:

סימן קיח דן במאכל כשר המופקד (מפקיד) או הנשלח (שולח) על ידי עובד כוכבים, ללא השגחה רצופה. החשש: העכו״ם יחליף (חליפין) אותו באיסור. התשובה: שלושה כלים. חותמות (חותם שאינו יכול לזייף), סימנים (סימני היכר — ניקור, אות, צורה), והנאמנות / מירתת (העכו״ם מתיירא שמא ייתפס, ולכן אינו מעז). המחבר (סעיף א) פוסק: יין, בשר, חתיכת דג בלא סימן → שני חותמות ; כל איסור מדברי סופרים (יין מבושל, שכר, חומץ, חלב, פת, גבינה) → חותם אחד.

💡 הסימן: סימן זה אינו עוסק בבישולי עכו״ם, אלא בשליטה על החליפין. או שהחפץ חתום (חותם שאינו יכול לזייף), או שיש בו סימן שהישראל מכיר, או שהעכו״ם מתיירא מלהחליף (שמא ייתפס). בלי אחד מן השלושה → חוששים לחליפין, ולכן אסור.

2. 3 שאלות־הרפלקס

■ כמה חותמות? (חותם / חותם בתוך חותם) — האם בחפץ יש חותם שהעכו״ם אינו יכול לזייף? ליין / בשר / דג בלי סימן → צריך שניים (חבי״ת) ; לאיסורי דרבנן (חמפ״ג) → חותם אחד (סעיף א).
↓ ואם לא, יש סימן?
■ האם יש סימן? (ניקור / אות / צורה) — בהעדר חותם, האם הישראל מכיר את החפץ: ניקור של ירך החתוכה כדרך שהוא חותך, אות, דפוס של גבינה? הסימן עומד במקום חותם (סעיף ג, ה).
↓ ואם לא, האם העכו״ם מתיירא?
■ האם העכו״ם מתיירא? (מירתת / נאמנות) — בלי חותם ובלי סימן: נשלח דרך מעבר לרבים, או הונח אצל עכו״ם יוצא ונכנס, או נמסר לעם הארץ → מתיירא שמא ייתפס → מותר (סעיף ז, ח, י).

⚖ טבלת ״חותם אחד או שניים״ (סעיף א)

חבי״ת = שני חותמות (חמרא / בשׂר / יין נסך / תירוש — או: יין, בשר, דג). חמפ״ג = חותם אחד (חומץ / מורייס / פת / גבינה — ועוד יין מבושל, שכר, חלב: כל איסור מדברי סופרים). שני טעמים לחילוק: רש״י — דמיו יקרים / חיבת נסך (היין והבשר ״יקרים״ או יש בהם חיבה) ; רשב״א — חבי״ת = חשש דאורייתא, חמפ״ג = דרבנן. רמ״א: י״א ששני חותמות אינם אלא בישראל חשוד ; אך ע״י עכו״ם חותם אחד מספיק לכל (ר״ת) — ובדיעבד סומכים על כך.

4. 5 כללי הזהב

  1. חבי״ת = שני חותמות, חמפ״ג = אחד. יין, בשר, דג בלי סימן → שניים ; כל איסור מדברי סופרים → אחד (מחבר סעיף א ; ט״ז ס״ק א).
  2. ע״י עכו״ם, חותם אחד מספיק לכל (ר״ת) — בדיעבד ; אך ישראל חשוד צריך כפול (רמ״א סעיף א).
  3. הסימן עומד במקום חותם. ירך החתוכה כדרך שהישראל חותך אחר נטילת הגיד, הניקור המוכר (חוט דידא, חוט שאצל החזה) → כשר בלי חותם (מחבר סעיף ה).
  4. דפוס = חותם אחד, לא כמה. אות אחת = חותם אחד, שתיים = שניים ; אך דפוס מוטבע בבת אחת, אף בכמה אותיות, אינו אלא אחד (מחבר סעיף ג).
  5. מירתת: העכו״ם שמתיירא שמא ייתפס אינו מחליף. מעבר לרבים, יוצא ונכנס, עם הארץ → מותר אף בלי חותם (מחבר סעיף ז, ח, י).

5. סימן זיכרון — עזר־הזיכרון ״חותם״

« ח-ו-ת-ם » — לפי החותם של סעיף א
  • חבי״ת / חמפ״ג: חבי״ת = שני חותמות, חמפ״ג = אחד (טבלת היסוד).
  • ועל ידי עכו״ם: נשלח ע״י עכו״ם → חותם אחד מספיק (ר״ת, בדיעבד).
  • תוי / סימן: ניקור מוכר, אות, צורה עומדים במקום חותם.
  • מירתת ודפוס: דפוס מוטבע בבת אחת = אחד ; ומירתת — העכו״ם מתיירא (מעבר לרבים, יוצא ונכנס) → מותר.
סולם הנאמנות בלי חותם (סעיף ז-י)
  • מעבר לרבים → מותר: מתיירא שמא יראהו עובר ושב
  • עם הארץ מוליך → נאמן, אף שאינו מוחזק בכשרות
  • יוצא ונכנס → מותר: ״עתה יבוא ויראני״
  • הודיע שישהה → אסור (שוב אינו מתיירא)

6. 4 המלכודות הקלאסיות

❌ מלכודת 1 — לחשוב שחותם אחד מספיק תמיד: לחבי״ת (יין, בשר, דג בלי סימן) הנשלח ע״י ישראל חשוד, צריך שני חותמות (חותם בתוך חותם), לא אחד. אחד מספיק רק לחמפ״ג (איסורי דרבנן) או — בדיעבד — כשעכו״ם מוליך (ר״ת). אין להכליל ״חותם אחד וזהו״ (סעיף א).
❌ מלכודת 2 — לבלבל דאורייתא ודרבנן: מספר החותמות הולך לפי חומרת האיסור (רשב״א). חבי״ת = חשש דאורייתא (יין נסך, בשר נבילה) → שניים ; חמפ״ג = דרבנן (פת, גבינה, שכר) → אחד. וכן בניקור (סעיף ה): לאיסור דאורייתא (בשר), חתיכה בלי סימן שחוששים לחליפיה אסורה ; לאיסור דרבנן (גבינות), אם מכיר מקצתן והן המובחרות → כולן מותרות.
❌ מלכודת 3 — לשכוח את המירתת ומקום הרבים: מאכל הנשלח בלי חותם אינו בהכרח אסור. דרך מעבר לרבים (סעיף ז) העכו״ם מתיירא שמא יתפסנו עובר ושב ; הונח אצל עכו״ם יוצא ונכנס (סעיף י), מתיירא ״עתה יבוא ויראני״. אך אם הודיע שישהה, שוב אינו מתיירא → אסור. ולכתחילה אין לשלוח בלי חותם.
❌ מלכודת 4 — דפוס = חותם אחד, ולא כמה: אות אחת כתובה = חותם אחד, שתי אותיות = שני חותמות (סעיף ג). אך דפוס מוטבע, אף שיש בו כמה אותיות, הוטבע בבת אחת → אינו אלא חותם אחד. אין לקרוא דפוס של שלוש אותיות כ״שלושה חותמות״. ובמקום שמומרים / כותים יודעים לכתוב, הכתב אינו סימן אלא למי שמכירו.

להלכה למעשה, היוועץ ברבך.

7. סיכום 13 הסעיפים — שורה לכל אחד

סעיףנושאהעיקר
1חותם אחד או שניים (חבי״ת / חמפ״ג)יין, בשר, דג בלי סימן → שני חותמות ; יין מבושל, שכר, חומץ, חלב, מורייס, פת, גבינה (איסור מדברי סופרים) → אחד. טעמים: רש״י (דמיו יקרים / חיבת נסך) ; רשב״א (חבי״ת = דאורייתא, חמפ״ג = דרבנן). יש אומרים: מפקיד שיראה שוב חותמו → אחד. רמ״א: עכו״ם → אחד מספיק לכל (ר״ת), בדיעבד.
2אין צורך לבדוק שניתמשחתם יפה, אין צורך לבדוק שנית ; אך אם בדק ואינו מכיר עוד את החותם → אסור, אף בשני חותמות (עי' סי' ק״ל ס״ח). רמ״א: רק אם יש לחוש לחליפין שהעכו״ם נהנה מהם, או ביין (נגיעה) ; אחרת אין חשש אף בחותם פגום.
3מה נחשב חותם (אות / דפוס)אות אחת = חותם אחד, שתי אותיות = שני חותמות ; הדפוסים, אף בכמה אותיות, = אחד (הוטבעו בבת אחת). יש אומרים: במקום שמומרים/כותים יודעים לכתוב, הכתב אינו סימן אלא למי שמכירו (עי' ק״ל ס״ו).
4מפתח וחותם ; השקמפתח וחותם = שני חותמות ; אך לדבר שדי בו חותם אחד, מפתח לבד אינו חותם. רמ״א: שק תפור/סגור אינו אף חותם אחד (אא״כ התפרים הפוכים פנימה) ; חתם את החפץ ואת השק = שני חותמות.
5סימן הניקורירך הנשלחת בלי חותם, אם חתוכה כדרך שהישראל חותך אחר נטילת הגיד → כשרה ; כל חתיכה שניכר בה ניקור ישראל (חוט דידא, חוט שאצל החזה). רמ״א: שאר החתיכות, אם חוששים לחליפין, אסורות — בבשר (דאורייתא) ; אך בדרבנן (גבינות), אם מכיר מקצתן שלא הוחלפו והן המובחרות → כולן מותרות.
6בהמה / עוף שחוטים בלי חותםבהמה או עוף שחוטים הנשלחים בלי חותם → אסורים (סימן השחיטה אינו סימן מובהק, אף העכו״ם יודע לשחוט).
7מעבר לרביםנשלח בלי חותם דרך מקום שרבים עוברים → מותר (העכו״ם מתיירא שמא יראהו עובר ושב ויחזיקנו כגנב) ; אך לכתחילה אין לשלוח בלי חותם (עי' סי' קכ״ט ס״ד).
8נאמנות המוליך (עם הארץ)הקונה בשר ושולחו ביד עם הארץ → נאמן, אף שאינו מוחזק בכשרות ; אין חוששים לחליפין ; ואף עבדי ישראל. יש מי שאומר: החשוד לאכול דברים המותרים שלא כדין, חשוד אף להחליף.
9נמצא ביד עכו״ם עם חותם / ״כשר״בשר/גבינה הנמצאים ביד עכו״ם עם חותם או ״כשר״ כתוב, אף בלי לדעת מי כתב → כשר (ידוע שמישראל), ובלבד שאין שם עכו״ם היודעים לכתוב. רמ״א: לקנות גבינות חתומות כדרך ישראל ; רק במקום שאין חוששים שהדפוסים נשארו ביד עכו״ם ; יש אוסרים ; בדיעבד אין להחמיר.
10להניח עכו״ם לבדו (יוצא ונכנס)להניח עכו״ם לבדו עם דברים שחליפיהם דאורייתא: אם יוצא ונכנס, או נשאר זמן רב בלי שהודיע שיישאר ובלי שנעל → מותר (מתיירא ״עתה יבוא ויראני״), אף שנהנה מהחליפין ; אך אם הודיע שיישאר → אסור ; אם אינו נהנה → מותר בכל אופן (עי' ר״ס קכ״ט).
11שתי קדירות זו אצל זושתי קדירות (ישראל + עכו״ם, אחת בשר כשר ואחת נבילה) → מותר ; אין חוששים לחליפין כשהישראל מסב פניו, אף שלו משובחת, אף מגולות (אין חשש ניתזין) — וכן שני צלאים ; אך לכתחילה ייזהר, אף בשתי קדירות.
12שפחותלהחמיר ושלא להניח הקדירות עם השפחות בהיעדר ישראל (וכשאינו יוצא ונכנס). רמ״א: אם נתנה שפחה איסור בקדירה, אין להאכילה לה (שלא להרגילה בכך).
13דפוס שנשכח ביד העכו״םישראל שעשה גבינות אצל עכו״ם וחתמן בדפוס של עץ ושכחו שם → אין חוששים שהעכו״ם יזייף אחרות ולא שהחליק הפנים בחזיר. רמ״א: י״א להתיר רק אם הניח הדפוס מונח על גבינותיו ; אחרת חשש חליפין (קטנות→גדולות) → אסור ; ובמקום הפסד מתירים.

⚖ הרפלקס ב־3 שאלות

  1. חותם? חבי״ת = שניים, חמפ״ג = אחד ; עכו״ם → אחד מספיק (ר״ת, בדיעבד). הדפוס אינו נמנה אלא לאחד.
  2. סימן? ניקור מוכר, אות, צורה עומדים במקום חותם ; ובגבינות, להכיר המובחרות מספיק.
  3. נאמנות / מירתת? מעבר לרבים, עם הארץ, יוצא ונכנס → מותר ; אך אם הודיע על שהייה ארוכה → אסור.
להלכה למעשה, היוועץ ברבך.
