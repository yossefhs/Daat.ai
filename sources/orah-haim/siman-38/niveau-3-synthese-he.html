1. האקסיומה המרכזית

עיקרון אוניברסלי של סימן ל״ח:

לאחר זמן המצווה (סימן ל״ז), הסימן הזה (י״ג סעיפים) שואל מי חייב ומי פטור מן התפילין. חמישה מפתחות מכוונים את כל הפטורים. ① הגוף: חולה מעיים פטור מתפילין, ומצטער ומי שאין דעתו מיושבת עליו ונכונה פטור מפני שאסור להסיח דעתו מהם. ② הדעת: המניח תפילין צריך ליזהר מהרהור תאות אשה, והקורא בתורה פטור מהנחת תפילין כל היום זולת בשעת ק״ש ותפלה. ③ המצב: נשים ועבדים פטורים מתפילין מפני שהוא מצות עשה שהזמן גרמא, אבל ביום ראשון אסור להניח תפילין, חתן ושושביניו וכל בני חופה פטורין משום דשכיח שכרות וקלות ראש. ④ המצווה: כותבי תפילין ומזוזות הם ותגריהם ותגרי תגריהם וכל העוסקים במלאכת שמים פטורים מהנחת תפילין כל היום זולת בשעת ק״ש ותפלה. ⑤ הדינים הנלווים: תפילין קודמין למזוזה ומנודה ומצורע אסורים להניח תפילין.
💡 המפתח האוניברסלי: הסימן אינו שואל עוד מתי להניח תפילין, אלא מי חייב בהן. חמישה מפתחות מכוונים כל פטור:
  • הגוף ← החולה, ההפחה, המצטער: כשאין הגוף יכול לעמוד בגוף נקי — חולה מעיים פטור מתפילין
  • הדעת ← ההרהור והקורא בתורה: חשש היסח הדעת — שאסור להסיח דעתו מהם
  • המצב ← נשים ועבדים (זמן גרמא), אבל, חתן ; אבל ט׳ באב חייב — מצות עשה שהזמן גרמא
  • המצווה ← הסופרים וכל העוסק במצווה — העוסק במצוה פטור מן המצוה
  • דינים נלווים ← חליצה בפני רבו, קדימה למזוזה, מנודה ומצורע — מנודה ומצורע אסורים להניח תפילין

הי״ג סעיפים של המחבר נערכים סביב ציר אחד — מי חייב ומי פטור — מקובצים בחמישה מפתחות: הגוף (①), הדעת (②), המצב (③), המצווה (④) והדינים הנלווים (⑤).

⚖ מבנה הסימן במבט אחד

כל הסימן נשען על יסוד אחד: מי חייב ומי פטור מן התפילין. הפטורים מתמצים בחמישה מפתחות: (①) הגוף שאינו יכול לעמוד בגוף נקי (חולה, הפחה, מצטער) ; (②) הדעת שיש בה חשש היסח הדעת (הרהור, קורא בתורה) ; (③) המצב — נשים ועבדים (זמן גרמא), אבל, חתן — ואילו ט׳ באב חייב ; (④) העיסוק במצווה אחרת (הסופרים) ; (⑤) הדינים הנלווים — אימת הרב, קדימת התפילין למזוזה, ואיסור המנודה והמצורע. גם השולחן ערוך הרב (אדמו״ר הזקן) מפתח סימן זה (בי״א סעיפים) — ראה רמה 4.

3. פטורי הגוף — חולה, גוף נקי, מצטער

ש: מתי הגוף פוטר מן התפילין?
↓
🟢 חולה מעיים — חולה מעיים פטור מתפילין (רמ״א: אפילו אין לו צער).
🟡 שאר חולה — פטור רק אם מצטער ואין דעתו מיושבת עליו ; ואם לאו חייב.
⚠ הפחה / גוף נקי — מוטב שיעבור זמן התפלה ממה שיתפלל בלא גוף נקי.
⚖ מצטער — מצטער ומי שאין דעתו מיושבת עליו ונכונה פטור מפני שאסור להסיח דעתו מהם.
📚 יסוד הגוף והגוף נקי: התפילין צריכים גוף נקי ודעת מיושבת. וכשאין הגוף יכול לעמוד בכך — פטור. החולה מעיים פטור אפילו אין לו צער — אף בלא צער — שאינו יכול להבטיח את נקיון הגוף. ושאר חולה אינו פטור אלא אם מצטער ואין דעתו מיושבת עליו ; ואם לאו חייב. ומי שברי לו שאינו יכול להתפלל בלא הפחה: מוטב שיעבור זמן התפלה ממה שיתפלל בלא גוף נקי — אבל אם יוכל להעמיד עצמו בגוף נקי בשעת ק״ש, יניח בין אהבה לק״ש ויברך (עי׳ סי׳ פ׳). ולבסוף המצטער שאין דעתו מיושבת פטור, מפני שאסור להסיח דעתו מהם. משמעות הגוף נקי והיסח הדעת מפותחת ברמה 2 (עי׳ סימן ל״ז וסימן מ״ד) ; הפסק ברמה 4.

4. הדעת — הרהור והקורא בתורה

ש: כיצד הדעת פוטרת מן התפילין?
↓
⚠ הרהור — המניח תפילין צריך ליזהר מהרהור תאות אשה ; ואם אי אפשר אחרת, מוטב שלא להניחם.
🟢 קורא בתורה — הקורא בתורה פטור מהנחת תפילין כל היום זולת בשעת ק״ש ותפלה.
⚖ היסוד — חשש היסח הדעת: התפילין רוצים דעת נתונה אליהן.
📚 יסוד הדעת: התפילין תובעים שלא יסיח אדם מהם דעתו. שתי דמויות מראות זאת. תחילה ההרהור: המניח תפילין צריך ליזהר מהרהור תאות אשה — המניחם צריך להיזהר מהרהורי עבירה ; ואם אי אפשר לו, פוסק הרמ״א: מוטב שלא להניחם. אחר כך הקורא בתורה — העוסק בלימוד פטור כל היום, הקורא בתורה פטור מהנחת תפילין כל היום זולת בשעת ק״ש ותפלה : הלימוד תופס את הדעת, אבל רצפת ק״ש ותפלה עומדת. היחס בין היסח הדעת כאן ובין יסוד סימן ל״ז (מצוותן כל היום אבל הגוף נקי) מפותח ברמה 2 ; הפסק ברמה 4.

5. פטורי המצב — נשים, אבל, ט׳ באב, חתן

ש: אילו מצבים פוטרים — ואילו מחייבים?
↓
🟢 נשים ועבדים — נשים ועבדים פטורים מתפילין מפני שהוא מצות עשה שהזמן גרמא ; רמ״א: ואם הנשים רוצים להחמיר על עצמן מוחין בידם.
🖤 אבל — אבל ביום ראשון אסור להניח תפילין ; מכאן ואילך חייב אפילו באו פנים חדשות.
🔴 ט׳ באב — אדרבה: בט׳ באב חייבין בתפילין.
🍷 חתן — חתן ושושביניו וכל בני חופה פטורין משום דשכיח שכרות וקלות ראש.
📚 יסוד המצב: יש מצבים באדם המשנים את החיוב. נשים ועבדים פטורים שהתפילין מצות עשה שהזמן גרמא — מצוה שהזמן גורם לה ; והרמ״א מוסיף שאם הנשים רוצים להחמיר, מוחין בידם (שלא כדעות אחרות שמניחות להן לברך — מחלוקת המפותחת ברמה 2). האבל, ביום ראשון, אינו מניח תפילין — אבל ביום ראשון אסור להניח תפילין — אבל מכאן ואילך חוזר להיות חייב, אפילו באו פנים חדשות. ולעומת זה ט׳ באב: בט׳ באב חייבין בתפילין — חייבים (ומניחים במנחה לפי המנהג, עי׳ סי׳ תקנ״ה). ולבסוף החתן ובני חופה פטורין, משום דשכיח שכרות וקלות ראש : השכרות וקלות הראש של החופה אינם מתיישבים עם כובד הראש שהתפילין תובעות.

6. העוסק במצווה — הסופרים

ש: מי שכבר עוסק במצווה, חייב בתפילין?
↓
🟢 הסופרים — כותבי תפילין ומזוזות הם ותגריהם ותגרי תגריהם וכל העוסקים במלאכת שמים פטורים מהנחת תפילין כל היום זולת בשעת ק״ש ותפלה.
⚖ הכלל — כל העוסק במצוה פטור ממצוה אחרת אם צריך לטרוח אחר האחרת.
✅ בלא טורח — אבל אם יכול לעשות שתיהן כאחת בלא טורח יעשה שתיהן.
📚 יסוד העוסק במצווה: הכלל כל העוסק במצוה פטור ממצוה אחרת (סוכה כה. – כו.) הוא המושל בסעיף זה. הכותבי תפילין ומזוזות, תגריהם, תגרי תגריהם וכל העוסקים במלאכת שמים פטורים מהנחת תפילין כל היום, זולת בשעת ק״ש ותפלה. והרמ״א מבאר את השיעור: הפטור אינו אלא אם צריך לטרוח אחר האחרת — אם צריך טורח למצוה השנייה ; אבל אם יכול לעשות שתיהן כאחת בלא טורח יעשה שתיהן. גבול הטורח, היחס למצווה עוברת והקשר לקורא בתורה מפותחים ברמה 2 ; הפסק ברמה 4.

7. דינים נלווים — חליצה, קדימה, מנודה

ש: אילו דינים נלווים חותמים את הסימן?
↓
🙇 חליצה בפני רבו — לא יחלוץ תפילין בפני רבו אלא יפנה לצד אחר מפני אימתו.
📜 קדימה — תפילין קודמין למזוזה (כשאין ידו משגת לשניהם).
🚫 מנודה ומצורע — מנודה ומצורע אסורים להניח תפילין.
📚 יסוד הדינים הנלווים: שלוש הלכות חותמות את הסימן. החליצה בפני רבו: לא יחלוץ תפילין בפני רבו אלא יפנה לצד אחר מפני אימתו — אין חולצין תפילין בפני הרב ; מפני האימה, פונה לצד ומסירם שלא בפניו. הקדימה: מי שהיה צריך לתפילין ומזוזה ואין ידו משגת לשניהם — תפילין קודמין למזוזה : התפילין קודמין (מצווה שבגופו). ולבסוף האיסור: מנודה ומצורע אסורים להניח תפילין — המנודה והמצורע אינם מניחים תפילין. גדר הקדימה (תדיר / מצווה שבגופו) ויסוד האיסור מפותחים ברמה 2 ; הפסק ברמה 4 (הפניה לרב). (על סדר הנחת התפילין, עי׳ סימן כ״ה ; על הגוף נקי, עי׳ סימן פ׳.)

8. כללי זהב — עזר לזיכרון

5 כללי הזהב של סימן ל״ח
  • הגוף — החולה מעיים, ההפחה, המצטער: כשאין הגוף יכול לעמוד בגוף נקי — חולה מעיים פטור מתפילין.
  • הדעת — ההרהור והקורא בתורה: חשש היסח הדעת — שאסור להסיח דעתו מהם.
  • המצב — נשים ועבדים (זמן גרמא), אבל, חתן ; אבל ט׳ באב חייב — מצות עשה שהזמן גרמא.
  • המצווה — הסופרים וכל העוסק במצווה, זולת בשעת ק״ש ותפלה — העוסק במצוה פטור מן המצוה.
  • דינים נלווים — חליצה בפני רבו, תפילין קודמין למזוזה, מנודה ומצורע — מנודה ומצורע אסורים להניח תפילין.

9. סימן זיכרון — עזר לזיכרון

חמשת מפתחות הפטור — "ג-ד-מ-מ-ד"
  • גוף — חולה, הפחה, מצטער: אין גוף נקי.
  • דעת — הרהור והקורא בתורה: היסח הדעת.
  • מצב — נשים ועבדים, אבל, חתן ; ט׳ באב חייב.
  • מצווה — הסופרים, העוסק במצווה.
  • דינים נלווים — רבו, קדימה למזוזה, מנודה ומצורע.
גוף, דעת, מצב, מצווה או דין? לזכור:
  • חולה מעיים פטור מתפילין — הגוף והגוף נקי.
  • מצות עשה שהזמן גרמא — נשים ועבדים.
  • העוסק במצוה פטור מן המצוה — הסופרים.
  • מנודה ומצורע אסורים להניח תפילין — האיסור.

10. מכשלות להימנע מהן

❌ מכשלה 1: לחשוב שכל חולה פטור מתפילין.
← הסעיף: רק החולה מעיים פטור אפילו אין לו צער ; שאר חולה — שאר חולה — אינו פטור אלא אם מצטער ואין דעתו מיושבת עליו, ואם לאו חייב (סעיף א).
❌ מכשלה 2: לחשוב שאישה הרוצה להניח תפילין מעודדים אותה לכך לפי המחבר.
← הסעיף: נשים ועבדים פטורים (מצות עשה שהזמן גרמא) ; והרמ״א: ואם הנשים רוצים להחמיר על עצמן מוחין בידם (סעיף ג).
❌ מכשלה 3: לחשוב שט׳ באב הוא יום פטור כמו יום ראשון של אבל.
← הסעיף: אבל ביום ראשון אסור (סעיף ה), אבל בט׳ באב חייבין בתפילין (סעיף ו) — זה פוטר וזה מחייב.
❌ מכשלה 4: להרחיב את פטור העוסק במצווה אף כשאפשר לעשות הכול בלא טורח.
← הסעיף: הפטור אינו אלא אם צריך לטרוח ; אבל אם יכול לעשות שתיהן כאחת בלא טורח יעשה שתיהן (סעיף ח).

11. ההנהגה במעשה

מקרההנהגההלכת היסוד
① הגוף (חולה, הפחה, מצטער) חולה מעיים פטור אפילו אין לו צער ; שאר חולה רק אם מצטער ואין דעתו מיושבת — לרב בספק גוף נקי
② הדעת (הרהור, קורא בתורה) ליזהר מהרהור ; הקורא בתורה פטור כל היום, אבל לעולם לא בשעת ק״ש ותפלה היסח הדעת
③ המצב (נשים, אבל, ט׳ באב, חתן) נשים ועבדים פטורים (רמ״א מוחין) ; אבל יום ראשון פטור ; ט׳ באב חייב ; חתן ובני חופה פטורים מצות עשה שהזמן גרמא
④ המצווה (הסופרים) הסופר והתגר פטורים כל היום זולת בשעת ק״ש ותפלה ; בלא טורח יעשה שתיהן העוסק במצוה פטור מן המצוה
⑤ דינים נלווים לא לחלוץ תפילין בפני רבו ; התפילין קודמין למזוזה ; מנודה ומצורע אסורים מנודה ומצורע אסורים

12. טבלת סיכום סופית

מפתחכללסימן
הגוף חולה מעיים פטור אפילו אין לו צער ; שאר חולה — אם מצטער ואין דעתו מיושבת עליו ; מצטער פטור מפני שאסור להסיח דעתו מהם סעיפים א · ב · ט
הדעת המניח תפילין צריך ליזהר מהרהור תאות אשה ; הקורא בתורה פטור כל היום זולת בשעת ק״ש ותפלה סעיפים ד · י
המצב נשים ועבדים פטורים (מצות עשה שהזמן גרמא, רמ״א מוחין) ; אבל ביום ראשון אסור ; בט׳ באב חייבין ; חתן ובני חופה פטורין משום שכרות וקלות ראש סעיפים ג · ה · ו · ז
המצווה כותבי תפילין ומזוזות ותגריהם וכל העוסקים במלאכת שמים פטורים כל היום זולת בשעת ק״ש ותפלה ; בלא טורח יעשה שתיהן סעיף ח
דינים נלווים לא יחלוץ תפילין בפני רבו מפני אימתו ; תפילין קודמין למזוזה ; מנודה ומצורע אסורים להניח תפילין סעיפים יא · יב · יג

✦ ❖ ✦ 5 מפתחות הפטור של סימן ל״ח בקיצור

  1. הגוף — החולה מעיים פטור אפילו אין לו צער ; אחרת צריך צער ודעת שאינה מיושבת — חולה מעיים פטור מתפילין.
  2. הדעת — ליזהר מהרהור ; הקורא בתורה פטור כל היום זולת בשעת ק״ש ותפלה — שאסור להסיח דעתו מהם.
  3. המצב — נשים ועבדים, אבל יום ראשון, חתן פטורים ; ט׳ באב חייב — מצות עשה שהזמן גרמא.
  4. המצווה — הסופרים פטורים זולת בשעת ק״ש ותפלה — העוסק במצוה פטור מן המצוה.
  5. הדינים — אין חליצה בפני הרב ; תפילין קודמין למזוזה ; מנודה ומצורע אסורים — מנודה ומצורע אסורים.
