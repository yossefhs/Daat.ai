1. האקסיומה המרכזית

עיקרון אוניברסלי של סימן קמ״ז:

סימן זה (ח׳ סעיפים) מברר את דיני גלילת ספר תורה — כיצד גוללין את הספר ומכבדין אותו. יסוד אחד: כבוד הספר. ① אין אוחזין את הספר ערום: אסור לאחוז ס״ת ערום בלא מטפחת. ② הגלילה כבוד היא: הגדול שבקוראים גולל, והגולל נוטל שכר כנגד כולם (מגילה ל״ב.). ③ כל הפרטים — כנגד התפר, המטפחת, התיק, המפטיר, שני ספרים — אינם אלא לכבד ולשמור את הספר.
💡 המפתח האוניברסלי: כל הסימן מברר שאלה אחת — כיצד גוללין את ספר התורה ומכבדין אותו? המקרים המרכזיים:
  • אחיזת ס״ת ערום ← אסור לאחוז ס״ת ערום בלא מטפחת
  • הגבהה וגלילה ← הגולל ספר תורה גוללו מבחוץ וכשהוא מהדקו מהדקו מבפנים
  • כנגד התפר ← הגולל ספר תורה יעמידנו כנגד התפר כדי שאם יקרע יקרע התפר
  • המפטיר ← אין המפטיר מתחיל עד שיגמרו לגלול הס״ת כדי שלא יהא הגולל טרוד ויוכל לשמוע ההפטרה

2. טבלת-אב של ח׳ הסעיפים

ח׳ הסעיפים של המחבר מבררים שמונה מצבים של הגלילה — מכבוד הספר (א׳) ועד ההנהגה בשני ספרי תורה (ח׳).

סעיףמקרהלב ההלכהסימן
א׳ אחיזת ס״ת ערום מטפחת · גדול גולל — אסור לאחוז ס״ת ערום בלא מטפחת. מטפחת
ב׳ מכירת הגלילה לא קנה המעילין — יכול מי שירצה לקנות להושיט המעילין להגולל ואין הגולל יכול למחות בו. המעילין
ג׳ כנגד התפר שאם יקרע יקרע התפר — הגולל ספר תורה יעמידנו כנגד התפר כדי שאם יקרע יקרע התפר. התפר
ד׳ הגבהה וגלילה מבחוץ · מהדקו מבפנים — הגולל ספר תורה גוללו מבחוץ וכשהוא מהדקו מהדקו מבפנים. מבפנים
ה׳ המטפחת המטפחת סביב הספר — מוטב תגלל המטפחת סביב הס״ת ולא יגלול הס״ת כשכורכו במטפחת. מטפחת
ו׳ הגלילה בתיק טועה — הגולל ס״ת בתוך התיק טועה. התיק
ז׳ המפטיר עד גמר הגלילה — אין המפטיר מתחיל עד שיגמרו לגלול הס״ת כדי שלא יהא הגולל טרוד ויוכל לשמוע ההפטרה. ההפטרה
ח׳ שני ספרי תורה סדר הגלילה וההנחה — ביום שיש ב׳ ספרי תורה לא יפתחו השניה ולא יסירו המפה עד שיגללו הראשון. ב׳ ספרים

⚖ מבנה הסימן במבט אחד

כל הסימן נשען על יסוד אחד: כבוד הספר במעשה הגלילה. מכאן (①) הכבוד לספר — אסור לאחוז ס״ת ערום בלא מטפחת ; (②) כבוד הגלילה — הגולל נוטל שכר כנגד כולם ; (③) פרטי הגלילה — כנגד התפר, המטפחת, התיק — וסדר הקהל (המפטיר, שני ספרים). לגישת אדמו״ר הזקן על סימן זה — ראה רמה 4 — דעת הרב (עמוד-מעבר).

3. כבוד הספר — אחיזת ס״ת ערום · מכירת המצוה

ש: כיצד אוחזין את ספר התורה, ולמי הגלילה?
↓
🟢 אחיזת ס״ת ערום — אסור לאחוז ס״ת ערום בלא מטפחת.
🔵 מכירת הגלילה — יכול מי שירצה לקנות להושיט המעילין להגולל ואין הגולל יכול למחות בו.
📚 יסוד כבוד הספר: אין אוחזין את הספר בבשר היד בלא מטפחת — אסור לאחוז ס״ת ערום בלא מטפחת : דין הוא בכבוד הספר (מגילה ל״ב., שם הגולל נוטל שכר כנגד כולם). ולכן נותנין את הגלילה לגדול שבקוראים, ומחבבין את המצוה בקנייתה בדמים יקרים (לחבב המצוה). ולענין המכירה: יכול מי שירצה לקנות להושיט המעילין להגולל ואין הגולל יכול למחות בו — מי שקנה את הגלילה לא קנה בכך את זכות הבאת המעילין: שתי מצוות נפרדות.

4. הגלילה — הגבהה וגלילה · פרטי הגלילה

ש: כיצד גוללין את הספר, ואילו זהירויות בשעת הגלילה?
↓
🟣 הגבהה וגלילה — הגולל ספר תורה גוללו מבחוץ וכשהוא מהדקו מהדקו מבפנים.
✨ כנגד התפר — הגולל ספר תורה יעמידנו כנגד התפר כדי שאם יקרע יקרע התפר ; מוטב תגלל המטפחת סביב הס״ת ולא יגלול הס״ת כשכורכו במטפחת ; הגולל ס״ת בתוך התיק טועה.
📚 יסוד הגלילה: גוללין את הספר מבחוץ ומהדקין מבפנים — הגולל ספר תורה גוללו מבחוץ וכשהוא מהדקו מהדקו מבפנים ; ובנוהגין שאחד מגביה ואחד גולל, הכתב נגד המגביה, עיקר הגולל, שנוטל שכר כנגד כולם (מגילה ל״ב.). ומעמידין את הספר כנגד התפר — הגולל ספר תורה יעמידנו כנגד התפר כדי שאם יקרע יקרע התפר — שאם יקרע, יקרע התפר ולא הכתב. וסוף דבר, מגלגלין את המטפחת סביב הספר (מוטב תגלל המטפחת סביב הס״ת ולא יגלול הס״ת כשכורכו במטפחת), ואין גוללין כשהספר בתוך התיק (הגולל ס״ת בתוך התיק טועה).

⚖ הכבוד וסדר הקהל — מן העיקרון אל המעשה (נקודות ①–③)

ח׳ הסעיפים יוצרים שרשרת סביב יסוד אחד — כבוד הספר במעשה הגלילה. יסוד זה (①) קובע את הכבוד לספר אסור לאחוז ס״ת ערום בלא מטפחת ; מברר (②) את המעשה הגולל ספר תורה גוללו מבחוץ וכשהוא מהדקו מהדקו מבפנים והגולל ספר תורה יעמידנו כנגד התפר כדי שאם יקרע יקרע התפר ; ומסדר (③) את הקהל אין המפטיר מתחיל עד שיגמרו לגלול הס״ת כדי שלא יהא הגולל טרוד ויוכל לשמוע ההפטרה, עד ביום שיש ב׳ ספרי תורה לא יפתחו השניה ולא יסירו המפה עד שיגללו הראשון.

5. כללי זהב — עזר לזיכרון

3 כללי הזהב של סימן קמ״ז
  • כבוד הספר — אין אוחזין את הספר ערום — אסור לאחוז ס״ת ערום בלא מטפחת.
  • מעשה הגלילה — מבחוץ, מהדקו מבפנים ; כנגד התפר — הגולל ספר תורה יעמידנו כנגד התפר כדי שאם יקרע יקרע התפר.
  • סדר הקהל — המפטיר ממתין לגמר הגלילה — אין המפטיר מתחיל עד שיגמרו לגלול הס״ת כדי שלא יהא הגולל טרוד ויוכל לשמוע ההפטרה.

6. סימן זיכרון — עזר לזיכרון

כבוד · מעשה · קהל — שלושת צירי סימן קמ״ז
  • ① כבוד הספר — לא לאחוז ערום בלא מטפחת ; גדול גולל, נוטל שכר כנגד כולם.
  • ② מעשה הגלילה — מבחוץ ומהדק מבפנים ; כנגד התפר ; המטפחת סביב ; לא בתיק.
  • ③ סדר הקהל — המפטיר עד גמר הגלילה ; שני ספרים — סדר ההנחה.
הביטויים המרכזיים לזכור:
  • אסור לאחוז ס״ת ערום בלא מטפחת — הכבוד.
  • הגולל ספר תורה יעמידנו כנגד התפר כדי שאם יקרע יקרע התפר — המעשה.
  • אין המפטיר מתחיל עד שיגמרו לגלול הס״ת כדי שלא יהא הגולל טרוד ויוכל לשמוע ההפטרה — הקהל.

7. מכשלות להימנע מהן

❌ מכשלה 1: לאחוז את הספר בבשר היד, בלא מטפחת.
← הסימן: אסור לאחוז ס״ת ערום בלא מטפחת — דין הוא בכבוד הספר ; והגלילה עצמה כבוד, הגולל נוטל שכר כנגד כולם (①).
❌ מכשלה 2: לגלול שלא בזהירות, או בתוך התיק, בלא להעמיד את הספר.
← הסימן: מעמידין כנגד התפר (שאם יקרע יקרע התפר), מגלגלין את המטפחת סביב הספר, והגולל ס״ת בתוך התיק טועה (②).
❌ מכשלה 3: להתחיל את ההפטרה בעוד הגולל טרוד במלאכתו.
← הסימן: אין המפטיר מתחיל עד שיגמרו לגלול — כדי שלא יהא הגולל טרוד ויוכל לשמוע ההפטרה ; ובשני ספרים, נזהרין בסדר שלא יסיחו דעתן מן המצוה (③).

8. ההנהגה במעשה

מקרההנהגההלכת היסוד
① אחיזת ס״ת ערום אין אוחזין את הספר ערום ; הגלילה לגדול שבקוראים אסור לאחוז ס״ת ערום בלא מטפחת
② הגבהה וגלילה גולל מבחוץ, מהדק מבפנים ; הכתב נגד המגביה הגולל ספר תורה גוללו מבחוץ וכשהוא מהדקו מהדקו מבפנים
③ כנגד התפר מעמידו כנגד התפר, שיקרע התפר ולא הכתב הגולל ספר תורה יעמידנו כנגד התפר כדי שאם יקרע יקרע התפר
④ המפטיר ושני ספרים המפטיר ממתין לגמר הגלילה ; סדר ההנחה בשני ספרים אין המפטיר מתחיל עד שיגמרו לגלול הס״ת כדי שלא יהא הגולל טרוד ויוכל לשמוע ההפטרה
