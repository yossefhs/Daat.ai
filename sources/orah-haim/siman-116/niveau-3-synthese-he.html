1. האקסיומה המרכזית

עיקרון אוניברסלי של סימן קט״ז:

סימן זה (סעיף אחד) מבאר את נוסח ברכת רפאנו. יסוד אחד: ① הפתיחה «רפאנו ה׳ ונרפא» לקוחה מן הכתוב «רפאני ה׳ וארפא» (ירמיה י״ז, י״ד), שנאמר ביחיד ונאמר ברבים. ② הכלל «אין מכנין» — שאין מסבים את הכתוב מן היחיד לרבים — אינו אלא «בזמן שמתכוין לקרות» ; אבל «דרך תפלה ובקשה» מותר להטות. ③ אלא במזמור שלם: שם אסור לשנות יחיד↔רבים.
💡 המפתח האוניברסלי: כל הסימן מברר שאלה אחת — כיצד אומרים את ברכת רפאנו בעוד שהכתוב שממנו נלקחה נאמר בלשון יחיד? הסעיף מכוון אותה:
  • הלשון ← רפאינו ה׳ ונרפא אע״פ דהכתוב ליחיד אין מכנין אותו לרבים
  • מתכוין לקרות ← ה״מ בזמן שמתכוין לקרות
  • דרך תפלה ובקשה ← אבל כשאומר אותו דרך תפלה ובקשה מותר
  • מזמור שלם ← ומ״מ אם אומר מזמור שלם אסור לשנות מלשון יחיד לרבים או להיפך

2. טבלת-אב של מרכיבי הסעיף

הסעיף היחיד של המחבר מברר ארבע נקודות בנוסח — מלשון הברכה (①) ועד גבול המזמור שלם (④).

#נקודהלב ההלכהסימן
① לשון הברכה יחיד → רבים — רפאינו ה׳ ונרפא אע״פ דהכתוב ליחיד אין מכנין אותו לרבים. רפאנו ה׳ ונרפא
② מתכוין לקרות אסור לשנות — ה״מ בזמן שמתכוין לקרות. אין מכנין
③ דרך תפלה ובקשה מותר להטות — אבל כשאומר אותו דרך תפלה ובקשה מותר. דרך תפלה ובקשה
④ מזמור שלם אסור לשנות — ומ״מ אם אומר מזמור שלם אסור לשנות מלשון יחיד לרבים או להיפך. מזמור שלם

⚖ מבנה הסימן במבט אחד

כל הסימן נשען על יסוד אחד: כיצד אומרים את ברכת רפאנו שהכתוב שממנו נלקחה נאמר בלשון יחיד? מכאן (①) הלשון — רפאינו ה׳ ונרפא אע״פ דהכתוב ליחיד אין מכנין אותו לרבים ; (②) הגבול בזמן שמתכוין לקרות ; (③) ההיתר דרך תפלה ובקשה מותר ; (④) הסייג אם אומר מזמור שלם אסור לשנות. גם השולחן ערוך הרב (אדמו״ר הזקן) מפתח סימן זה בסעיף אחד — ראה רמה 4.

3. הלשון — הכתוב והברכה

ש: מדוע אומרים «ונרפא» (רבים) בעוד שהכתוב «וארפא» (יחיד)?
↓
🟢 הכתוב — רפאני ה׳ וארפא הושיעני ואושעה כי תהלתי אתה (ירמיה י״ז, י״ד), בלשון יחיד.
🔵 הברכה — רפאינו ה׳ ונרפא אע״פ דהכתוב ליחיד אין מכנין אותו לרבים : נאמרת ברבים, שהיא תפלה על הכלל ולא קריאת הכתוב.
📚 יסוד הלשון: פתיחת הברכה בנויה על הכתוב בירמיה רפאני ה׳ וארפא הושיעני ואושעה כי תהלתי אתה, שנאמר בלשון יחיד ; ובכל זאת אנו אומרים רפאנו ה׳ ונרפא בלשון רבים. הכלל הוא אין מכנין אותו לרבים — שאין מסבים את הכתוב מיחיד לרבים — אבל אין זה אלא בזמן שמתכוין לקרות (קריאה או תרגום) ; ואילו נוסח הברכה אינו קריאת הכתוב אלא תפלה על הכלל, ומשום כך הרבים כשר.

4. הגבולות — מזמור שלם · תפלה על החולה

ש: מתי מותר להטות את הכתוב, ומתי אסור?
↓
🟣 דרך תפלה ובקשה — אבל כשאומר אותו דרך תפלה ובקשה מותר : פסוק שמטהו לצורך תחינתו — מותר להטותו.
✨ מזמור שלם — ומ״מ אם אומר מזמור שלם אסור לשנות מלשון יחיד לרבים או להיפך : האומר מזמור שלם כסדרו — כקורא את הכתוב, ואינו משנה.
📚 יסוד הגבולות: איסור ה«כינוי» תלוי במעשה: הקורא (מתכוין לקרות) חייב בנאמנות ללשון הכתוב ; המתחנן (דרך תפלה ובקשה) רשאי להטות את הכתוב לפי צורך השעה — ומכאן אבל כשאומר אותו דרך תפלה ובקשה מותר. אבל מזמור שלם הנאמר כסדרו חוזר להיות «קריאה», ומכאן ומ״מ אם אומר מזמור שלם אסור לשנות מלשון יחיד לרבים או להיפך. יישום: הואיל וברכת רפאנו היא ברכת הרפואה, מזכירים בה תפלה על החולה (תמצית: עד שלא תתחתם — קודם שיחתום «רופא חולי עמו ישראל»), שהוא דרך תפלה ובקשה (עי׳ סי׳ קי״ט ; ברכות ל״ד. ; עבודה זרה ח׳.).

⚖ מן הלשון אל הסייג — מן העיקרון אל המעשה (נקודות ①–④)

הסעיף יוצר שרשרת סביב עיקרון אחד — לומר את ברכת רפאנו בעוד שהכתוב שממנו נלקחה נאמר בלשון יחיד. עיקרון זה (①) קובע את הלשון רפאינו ה׳ ונרפא אע״פ דהכתוב ליחיד אין מכנין אותו לרבים ; מציב (②) את הגבול ה״מ בזמן שמתכוין לקרות ; פותח (③) את ההיתר אבל כשאומר אותו דרך תפלה ובקשה מותר ; וחותם (④) ומ״מ אם אומר מזמור שלם אסור לשנות מלשון יחיד לרבים או להיפך.

5. כללי זהב — עזר לזיכרון

3 כללי הזהב של סימן קט״ז
  • הלשון — הכתוב ביחיד, הברכה ברבים — רפאינו ה׳ ונרפא אע״פ דהכתוב ליחיד אין מכנין אותו לרבים.
  • ההיתר — קריאה: אסור ; תפלה ובקשה: מותר — ה״מ בזמן שמתכוין לקרות אבל כשאומר אותו דרך תפלה ובקשה מותר.
  • הסייג — מזמור שלם: אסור לשנות — ומ״מ אם אומר מזמור שלם אסור לשנות מלשון יחיד לרבים או להיפך.

6. סימן זיכרון — עזר לזיכרון

לשון · תפלה · סייג — שלושת צירי סימן קט״ז
  • ① הלשון — «רפאני» ביחיד, «רפאנו» ברבים (אין מכנין).
  • ② ההיתר — מתכוין לקרות: אסור ; דרך תפלה ובקשה: מותר.
  • ③ הסייג — מזמור שלם: אסור לשנות יחיד↔רבים.
הביטויים המרכזיים לזכור:
  • רפאינו ה׳ ונרפא אע״פ דהכתוב ליחיד אין מכנין אותו לרבים — הלשון.
  • ה״מ בזמן שמתכוין לקרות אבל כשאומר אותו דרך תפלה ובקשה מותר — ההיתר.
  • ומ״מ אם אומר מזמור שלם אסור לשנות מלשון יחיד לרבים או להיפך — הסייג.

7. מכשלות להימנע מהן

❌ מכשלה 1: לחשוב שיש לומר את הברכה ביחיד «רפאני» כדי לשמור על נאמנות לכתוב.
← הסימן: אין מכנין אינו אלא בזמן שמתכוין לקרות ; והברכה תפלה על הכלל היא, ונאמרת ברבים רפאנו ה׳ ונרפא (①).
❌ מכשלה 2: לחשוב שלעולם אין מטים פסוק מיחיד לרבים.
← הסימן: אבל כשאומר אותו דרך תפלה ובקשה מותר — בתפלה מטים את הכתוב לפי הצורך (②–③).
❌ מכשלה 3: לשנות יחיד↔רבים אף בתוך מזמור שלם הנאמר כסדרו.
← הסימן: ומ״מ אם אומר מזמור שלם אסור לשנות מלשון יחיד לרבים או להיפך — מזמור שלם חוזר להיות «קריאה» (④).

8. ההנהגה במעשה

מקרההנהגההלכת היסוד
① הלשון הכתוב ביחיד, הברכה ברבים: כשר (תפלה על הכלל) רפאינו ה׳ ונרפא אע״פ דהכתוב ליחיד אין מכנין אותו לרבים

③ דרך תפלה ובקשה בתפלה: מותר להטות לפי הצורך אבל כשאומר אותו דרך תפלה ובקשה מותר
