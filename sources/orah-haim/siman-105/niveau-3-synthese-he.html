1. האקסיומה המרכזית

עיקרון אוניברסלי של סימן ק״ה:

סימן זה (סעיף אחד) מברר מה עושה המתפלל שתי תפילות זו אחר זו — כגון שחרית ומוסף, או תשלומין למי ששכח. יסוד אחד: התפילה תחנונים ובקשת רחמים היא, ואין לגרור שתי תפילות בלא ריווח. ① שיעור המתנה קצוב: כדי הילוך ד׳ אמות. ② טעם: כדי שתהא דעתו מיושבת להתפלל בלשון תחינה. ③ מקום: המתפלל שנית במקומו — די בהמתנת ד׳ אמות ; אבל החוזר למקומו — כמו שיתבאר בסימן קכ״ג.
💡 המפתח האוניברסלי: כל הסימן מברר שאלה אחת — מה עושה המתפלל שתי תפילות זו אחר זו? וההלכה בפסוק אחד:
  • העיקרון ← המתפלל שתי תפלות זו אחר זו צריך להמתין בין זו לזו כדי הילוך ד׳ אמות כדי שתהא דעתו מיושבת להתפלל בלשון תחינה
  • החוזר למקומו (שולחן ערוך הרב) ← אבל לחזור למקומו אפילו אינו רוצה להתפלל שנית צריך להמתין כמו שיתבאר בסימן קכ״ג

2. טבלת-אב של הסעיף היחיד

הסעיף היחיד של המחבר נפרש בשלושה צירים של המתפלל שתי תפילות — הנושא, השיעור, הטעם — ועליהם מוסיף השולחן ערוך הרב את דין החוזר למקומו.

צירמקרהלב ההלכהסימן
הנושא שתי תפילות זו אחר זו שתי עמידות ברצף — המתפלל שתי תפלות זו אחר זו צריך להמתין בין זו לזו (כגון שחרית ומוסף, או תשלומין). להמתין
① שיעור ההמתנה כדי הילוך ד׳ אמות — צריך להמתין בין זו לזו כדי הילוך ד׳ אמות. ד׳ אמות
② טעם ההמתנה דעתו מיושבת · לשון תחינה — כדי שתהא דעתו מיושבת להתפלל בלשון תחינה. תחינה
③ חוזר למקומו כדין סי׳ קכ״ג — אבל לחזור למקומו אפילו אינו רוצה להתפלל שנית צריך להמתין כמו שיתבאר בסימן קכ״ג. קכ״ג

⚖ מבנה הסימן במבט אחד

כל הסימן נשען על יסוד אחד: התפילה תחנונים, ואין גוררים שתי תפילות בלא ריווח. מכאן (①) השיעור — כדי הילוך ד׳ אמות ; (②) הטעם — כדי שתהא דעתו מיושבת להתפלל בלשון תחינה ; (③) המקום — המתפלל שנית במקומו די בהמתנת ד׳ אמות, אבל החוזר למקומו כמו שיתבאר בסימן קכ״ג. גם השולחן ערוך הרב (אדמו״ר הזקן) מפתח סימן זה בסעיף אחד — ראה רמה 4.

3. השיעור — כדי הילוך ד׳ אמות

ש: כמה זמן להמתין בין שתי התפילות?
↓
🟢 שיעור ההמתנה — המתפלל שתי תפלות זו אחר זו צריך להמתין בין זו לזו כדי הילוך ד׳ אמות.
🔵 עומד במקומו (שולחן ערוך הרב) — אפילו אינו רוצה לחזור למקומו אלא מתפלל שנית במקום שעומד שם כשפסע אחר תפלה הראשונה — די בהמתנת ד׳ אמות.
📚 יסוד השיעור: שיעור ההמתנה הוא כדי הילוך ד׳ אמות — הזמן הנצרך להלך ארבע אמות. והוא כשיעור שבסוף העמידה: הפוסע ג׳ פסיעות לאחוריו אינו חוזר למקומו עד ששוהה כדי הילוך ד׳ אמות (עי׳ סי׳ קכ״ג). ואין זה דווקא הילוך בפועל אלא שיעור זמן, וכדקדוק אדמו״ר הזקן דהיינו כדי הילוך ד׳ אמות — שהמתנה זו סגי, בין עמד במקומו בין הילך.

4. הטעם והחזרה למקום — דעתו מיושבת · לשון תחינה · סי׳ קכ״ג

ש: מדוע להמתין — ומה דין החוזר למקומו?
↓
🟣 טעם ההמתנה — כדי שתהא דעתו מיושבת להתפלל בלשון תחינה ; ובלשון אדמו״ר הזקן כדי שתהא דעתו מיושבת לערוך דבריו בלשון תחינה.
✨ חוזר למקומו — אבל לחזור למקומו אפילו אינו רוצה להתפלל שנית צריך להמתין כמו שיתבאר בסימן קכ״ג.
📚 יסוד הטעם: מדוע להמתין? כדי שתהא דעתו מיושבת להתפלל בלשון תחינה — התפילה תחנונים ובקשת רחמים, והגורר שתי תפילות בלא ריווח מתפלל את השנייה בלא ישוב הדעת, כמצות אנשים מלומדה. ההמתנה מיישבת את דעתו ומאפשרת להתפלל בלשון תחינה. ולענין המקום: המתפלל שנית במקום שעמד אחר שפסע — די בהמתנת ד׳ אמות ; אבל הרוצה לחזור למקומו הראשון — אף בלא תפילה שנייה — ממתין כדין סוף התפילה, כמו שיתבאר בסימן קכ״ג (קשר לסי׳ צ״ח לכוונה, וסי׳ קכ״ג לפסיעות ולחזרה).

⚖ השיעור והטעם — מן העיקרון אל המעשה (נקודות ①–③)

הסעיף היחיד יוצר שרשרת סביב יסוד אחד — התפילה תחינה. יסוד זה קובע (①) את השיעור צריך להמתין בין זו לזו כדי הילוך ד׳ אמות ; נותן (②) את הטעם כדי שתהא דעתו מיושבת להתפלל בלשון תחינה ; ומברר (③) את המקום אבל לחזור למקומו אפילו אינו רוצה להתפלל שנית צריך להמתין כמו שיתבאר בסימן קכ״ג.

5. כללי זהב — עזר לזיכרון

3 כללי הזהב של סימן ק״ה
  • השיעור — בין שתי תפילות ממתין כדי הילוך ד׳ אמות — המתפלל שתי תפלות זו אחר זו צריך להמתין בין זו לזו כדי הילוך ד׳ אמות.
  • הטעם — שתתיישב דעתו, להתפלל בלשון תחינה — כדי שתהא דעתו מיושבת להתפלל בלשון תחינה.
  • המקום — במקומו: ד׳ אמות ; חוזר למקומו: סי׳ קכ״ג — אבל לחזור למקומו אפילו אינו רוצה להתפלל שנית צריך להמתין כמו שיתבאר בסימן קכ״ג.

6. סימן זיכרון — עזר לזיכרון

שיעור · טעם · מקום — שלושת צירי סימן ק״ה
  • ① שיעור — כדי הילוך ד׳ אמות בין תפילה לתפילה.
  • ② טעם — דעתו מיושבת ; לשון תחינה.
  • ③ מקום — במקומו: ד׳ אמות ; חוזר למקומו: סי׳ קכ״ג.
הביטוי המרכזי לזכור:
  • המתפלל שתי תפלות זו אחר זו צריך להמתין בין זו לזו כדי הילוך ד׳ אמות כדי שתהא דעתו מיושבת להתפלל בלשון תחינה — כל הסימן.
  • אבל לחזור למקומו אפילו אינו רוצה להתפלל שנית צריך להמתין כמו שיתבאר בסימן קכ״ג — החוזר למקומו (שולחן ערוך הרב).

7. מכשלות להימנע מהן

❌ מכשלה 1: לגרור שחרית ומוסף (או תפילה ותשלומיה) בלא ריווח כלל.
← הסימן: צריך להמתין בין זו לזו כדי הילוך ד׳ אמות — ממתין ביניהן כדי הילוך ד׳ אמות (①).
❌ מכשלה 2: לראות בהמתנה זו הפסק צורני בלבד.
← הסימן: תכליתה כדי שתהא דעתו מיושבת להתפלל בלשון תחינה — שתתיישב הדעת ותיאמר השנייה בתחינה ולא כמצות אנשים מלומדה (②).
❌ מכשלה 3: לחשוב שהחזרה למקומו הראשון אינה טעונה דבר.
← השולחן ערוך הרב: במקומו — ד׳ אמות ; אבל לחזור למקומו, אף בלא תפילה שנייה, כמו שיתבאר בסימן קכ״ג (③).
